# 568: 경계에서의 민감도 계측과 후반 제약 모델 진단

567 실패 기록은 보존했다. 당시 원시 실패 행이 없어 정확한 게이트는 여전히 미확인이다. 568은 565의 정확한 raw 528 체크포인트, launch 55/384와 tracking 64/1728 이력을 재사용했다. 저장된 seed의 재생이나 기존 whole replay를 반복하지 않았다.

각 raw의 전체 물리 상태와 행동·누적 이력 식별자를 힘 평가 전에 fsync하고, 힘·정확한 `ratio > 1` clipping·제안 누적 이력·판정을 틱 전에 다시 fsync하도록 계측했다. 틱 전후와 body 영역, 후속 기하 판정도 연결해 기록했다. 입력 저장 실패, 판정 후 실패, force/clip 위반, body 100 경계 등을 주입한 단위검사 6개가 통과했다. 원시 상태는 비공개 디렉터리에만 저장했다.

민감도는 별도의 진단 rollout으로 계산했다. 보통의 force/clip/기하/reference 위반은 기록하고 계속하되, 모든 물리 상태의 유한성·행동 영역·body < 100·비용 상한을 강제했다. 이 probe는 정책 incumbent로 표시하지 않는다. 실제 정책 후보의 원551 reference와 전역 안전 기준은 그대로 두었다.

FD 80열, 고정 보정 2회, 진단 복구 제안 2회를 완료했다. 이 실행의 FD 01-07에서는 raw 585 평가 직전 force peak 1.0590661123이 1.059를 넘었다. 누적 이력은 68/1952에서 69/1956이었다. 해당 위반을 보존하고 진단 rollout을 마쳤다. 이는 568의 새 관측이며 567 원인을 소급 확정하지 않는다.

안전 후보는 나오지 않았다. 보정 오차를 양의 내부 여유로 바꾸는 기존 규칙이 수학적으로 불가능한 목표를 만들었다. path slack은 `3 - distance`여서 최대 3m인데, 19개 raw의 고정 내부 목표가 이를 초과했다. 최대 목표는 raw 659의 4.822259m였다. 같은 raw에서 seed의 부호 있는 횡방향 오차는 -0.048m, 두 보정은 -1.311m와 +1.198m였다. 한 방향이 중심선을 지나면서 선형 모델은 불가능한 음의 거리를 예측했고, 이를 오차의 두 배로 보정하면서 목표 자체가 모순되었다. 이 결과는 후반 방향이나 안전 정책의 불가능성을 뜻하지 않는다.

두 복구의 내부 잔차 감소는 0.569%, 0.778%로 사전 요구한 10%에 못 미쳤고, 실제 footprint/reference 게이트도 통과하지 못했다. 원래 종료 코드 `TWO_NONDECREASING_RESTORATIONS`는 이 진행 부족을 가리킨다. 잔차가 문자 그대로 증가하거나 같았다는 뜻은 아니다. feedback 호출·새 incumbent·최종 whole replay는 0회다. 소스상 공식 tracker incumbent는 candidate raw 661, 확인 raw 662, 13.22초로 유지했다. 새 실제 주행 기록은 없다.

사용 비용은 소스 11,256틱, 힘 평가 45,024회, 기하 검사 11,256회, 최대 body 96.932857, CPU 267.50초, wall 285.05초다. 이전 567의 1,224틱은 별도이며 중복 합산하지 않았다. 읽기 전용 감사·분석은 약 4초이며 소스 틱은 0이다. 해시 연결 이벤트 56,448개와 모든 raw의 힘·clipping·body 판정을 감사했고, unsafe probe 56개 raw가 정책 eligible로 표시되지 않았음을 확인했다. Native 행동·reset·보호 평가·유료 자원·예비 사용은 모두 0이다.

다음 수정 대상은 내부 제약 모델이다. 중심선에서 부호가 바뀌는 거리를 직접 선형화해 여유를 더하는 대신, 부호 있는 횡방향 오차의 양측 제약이나 위치 벡터 잔차로 모델링하고, 내부 목표의 이론적 상한부터 검사해야 한다. 실제 footprint/path/reference 및 공식 tracker 승격 게이트는 그대로 유지한다. 이번 고정 보정값을 실행 도중 완화하거나 568을 재실행하지 않았다.

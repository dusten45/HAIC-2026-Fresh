# 357 현재 직접 검출 보호 가설의 캐시 반증

**저장 자료의 보존 게이트와 N2 효과 유지 검증은 통과했다. 실제 완주나 일반화 검증은 아니다.** 기존 349는 그대로 보존하고 별도 비공개 후보를 만들었다.

유일한 정책 변경은 hard routing 선택이다. 현재 직접 검출(age 0)은 항상 포함하고, age > 0인 retained 점에만 기존 low 출생 플래그 제외를 적용한다. `retry/nominal238_base.py` 한 멤버만 다르며 detector·출생 플래그·tracker·dedup·expiry·전체 hazards 특징·H1 모델·controller·fallback은 같다.

|---|---|
| 기존 349 대조군 | `ef1965a5b09ec9324498643842badbcd972c48fb7c141770d7cce88fe6496208` |
| 새 357 후보 | `b03a65de6410b2fa4805eefcd7a5a05ec246fc27843bdc40facc938927e665ad` |

두 arm에는 같은 수동 관측기를 사용했다. 기존 관측기의 “low면 제외” 가정 대신 ZIP이 실제 전달한 routing 부분집합을 기록한다. 관측기가 점을 선택하지 않으며, 기존 342/355 결과의 baseline 재현으로 이 계측 변경을 확인했다. 지원점 감사도 low 플래그만으로 실패를 세지 않고 **실제로 제외된 UID**를 확인한다. 원래 지원점 제외 금지 요구는 약화하지 않았다.

검사 범위는 기존 342의 11궤적과 355 한 궤적, 합계 **2,792개 입력 문맥**이다.

| 증거 종류 | 입력 문맥 | 알려진 지원 직접 검출 | 출생 지원 retained 문맥 | 새 후보 제외 |
|---|---:|---:|---:|---|

649개는 지원된 원시 직접 출생 전체와도 일치해 분모 누락이 없었다. 출생 GT가 없는 직접 12·retained 16문맥은 지원성 미확인으로 남긴다. 이들은 low 출생이 없는 자료에서 routing 포함이 증명됐지만, 지원 라벨을 임의로 붙이지 않았다. 숫자는 중복 N2 접두를 포함한 점 문맥 수이며 독립 물체·독립 시행 수가 아니다.

low가 전혀 없는 T2950·T2953·T2956·N2_333B·N2_330_A·N2_331B는 모든 flag가 false이고 두 정책의 routing 입력이 항상 전체 hazards라는 불변식으로 포함했다. 이 1,121개를 새 actor 출력으로 표시하지 않는다. 나머지는 아래처럼 실제 actor를 각각 reset하고 반환된 전체 조작을 commit하며 정상 기억으로 순차 재생했다.

**T2954 반례:** 92의 fixture 지원 직접 점은 새 후보에서 실제 routing에 들어갔다. 전체 356개 입력의 경로·목표·특징·조작·명목 기억은 대조군과 같다. 이는 356의 소스 의존성 추론을 이번 **실제 actor 재생**으로 확인한 것이다. 출생 메타데이터의 low 플래그 자체는 여전히 true이므로 분류기가 수정됐다고 주장하지 않는다. 기존 349의 지원 직접 점 제외 1건은 대조군에 그대로 남고 새 후보에서는 0건이다.

**N2 retained 효과:** 두 궤적 모두 전체 233개 경로·특징·제어·명목 기억이 기존 349와 같다. 필요한 121:0의 제외는 127–129에 age 6·7·8로 유지됐다. 필터 없는 342 기준 기록과 비교하면 경로 변화는 127–129, 목표 변화는 128–129, 첫 전체 조작 차이는 127, 첫 조향 차이는 128로 유지된다. 실제 actor 출력과 자격 있는 저장 기준을 대조한 결과이며 새로운 물리 궤적이나 완주 결과는 아니다.

**O2 변화:** 보호된 fresh 점 때문에 기존 349와 다른 경로·목표가 146에서 나오고, float32 조작은 146–153, 명목 기억은 146–166, 특징은 146–167까지 달라졌다. 이 변화는 정상 자기 기억의 실제 재생 결과다. 입력은 원래 다른 정책이 생성한 저장 영상이므로 실제 회귀·개선이나 기존 current334 O2 실제 궤적과 동일한 노출이라고 해석하지 않는다. N2 유지 외의 행동이 모두 그대로라고 주장하지 않는다.

정확한 새 호출은 **act 3,342 + commit 3,342 + 저장 영상 reset 12회**다. 사전 등록한 act 3,342·reset 12 상한을 지켰다. standalone routing 추가 호출·새 환경 reset·native·학습은 0이다. actor 내부에서는 정상 routing 계산이 수행됐다.

초기 입력 경로 자료형 오류는 actor/reset/native 0회에서 발생했다. 원본 실패를 보존하고 호스트 읽기 함수의 `str → Path` 변환만 별도 adapter로 보정했다. 원래 등록 runner·정책·자료·가설·호출 상한을 바꾸지 않았고 추가 actor 호출은 없었다. 초기 실패 wall/CPU는 각각 0.230초다. 정상 실행은 wall **64.313초**, runner CPU **30.380초**, actor CPU **35.853초**이며 마감 계산은 별도다. 코딩·패키징·문서화·git 전체 시간은 포함하지 않는다.

판단은 **알려진 캐시 자료에서 자격 통과한 연구후보**다. 진짜 low 출생이 재검출 없이 유지되면 나중에 retained로 제외될 수 있으므로 실제 가림 보존이나 일반 안전성은 아직 입증하지 못했다. 355의 실제 완주 성적은 원래 349의 기록이며 새 357의 실제 완주로 옮기지 않는다. 별도 실제 에피소드·split 개봉·승격은 하지 않았다.

연구 **1,644회**, 최종 예비 **84,000회**를 보존했다. 다음 실제 질문을 별도 등록한다면 T29511의 미측정 회귀가 우선이며, 정상 2,000 상한에는 현재 잔액보다 356회가 더 필요하다. 이는 비용 설명일 뿐 예산 배정·주행 예약이 아니다. 기존 349·champion 296·main·Participants·사용자 변경·백업을 보존했고 원본 관측·GT·seed·모델·개인 문서는 비공개로 유지했다.

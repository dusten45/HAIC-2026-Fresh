# 324: 추가 관측 이력이 실제 개입 선택에 주는 정보

**작은 캐시 반증 실험을 완료했고, 이 고정 이력 확장은 게이트에서 기각했다.** 현재16 대비 이력76은 실제 결과 조회에서 21/24 → 22/24 완주로 개선했지만 no-change의 24/24를 보존하지 못했다. 평균 return 이득도 음수다. 296을 유지하고 새 native·DEV·HOLDOUT·SEALED·champion 변경은 진행하지 않았다. 연구 전체 종료를 선언하는 결과는 아니다.

검토 후보는 두 개였다. 선택한 가설은 같은 실제 개입 결과에 최근 3단계 관측 특징·실행 행동만 추가하는 대조다. 비교 후보인 원시 픽셀 outcome 예측기는 292의 CNN return 실패와 가까우며 모델과 정보를 함께 변경하므로 이번 최소 실험에서는 제외했다. 코드와 결과에서 282의 CART는 현재16, 283의 실제 return-gain ridge도 현재16뿐임을 확인했다. 과거 imitation의 previous action·tracker history, 277의 sampled return predictor, 318의 순간 상태 회귀가 있었지만 같은 실제 개입 이득 표적에 추가3단계 입력만 대조한 실험은 없었다. History나 ridge 자체가 처음이라는 주장은 아니다. 315는 teacher pedal 1NN이며 이번 표적·비교군과 다르다.

문제 계약의 적법 영상·자기 행동 경계, 공식 완주 우선 목적과 실패 분석의 인과적 비교·작은 반증 원칙을 적용했다. 결과 전에 24개 기존 TRAIN 상태, 여섯 도로, 입력·표적·LORO·비용·중단·게이트를 비공개 plan과 SHA로 등록했다. 새 pulse·threshold·route cost·gain·teacher·PPO 변형은 만들지 않았다. 기존 개입 library는 측정된 표적 조회에만 사용했다.

현재16의 283 예측을 그대로 재사용하고 저장된 모델로 정확히 재현했다. B는 현재16 + lag1/2/3 특징16 + lag1/2/3 실행 action3 + 유효 mask3 =76이다. 현재16 자체도 tracker·controller memory를 포함하므로 완전 무기억 정책과의 대조는 아니다. 현재·미래 개입 명령, GT, 진행률, 시간, 보상, 도로 ID는 입력에 없다. 시간은 인과적 정렬 검증에만 사용했다. 현재 pre-action 픽셀은 이전 행동의 post-action hash와 일치함을 검증했고, 과거 특징·실행 명령·80ms 경계도 확인했다.

표적은 동일24 상태의 측정된96 macro 이득이다. 완주 return `2−T/160`, 실제 DNF return `p−1`에서 같은 상태의 no-change return을 뺀다. 96개 공식 terminal receipt와 기존 표적을 정확히 검증했다. GT teacher 명령이나 순간 상태 회귀가 아니다. 표적·lambda1·비정규화 bias·TRAIN fold mean/std·선택 규칙은 283 그대로이며 입력만 바꿨다. 각 도로의 네 상태를 모두 제외하고 다른20개로 fit하는 여섯 LORO만 수행했다. 인접 행 train/test 혼합, 최종24상태 fit, 이력 길이·특징·lambda 탐색은 없다. 유일한 양수 최대 이득만 선택하며 동률·비양수면 baseline으로 기권한다.

사전 게이트는 B의 **24/24 완주 유지**, baseline 대비 엄격한 양수 평균 return 이득, A보다 큰 평균 이득, 선택 차이 발생이었다. 통과해도 알려진240의 일회성 결과 조회에 한정하며 296의 반복 정책·native 승인을 의미하지 않도록 정했다.

B와 A의 선택은 12/24에서 달랐다. A 대비 완주 추가2·손실1이며 둘 다 완주한20개에서 B−A 시간 차이는 평균 −52ms다. 서로 다른 완주 부분집합 평균을 직접 빼지 않았다. B가 선택한18개 비baseline 개입의 저장 trace에서 실제로 달라진54개 명령을 확인했다. 새 actor 호출은 없다.

B는 N2 query136·202에서 gas-upper를 선택해 두 실제 DNF를 남겼다. A의 N2 query67 실패와 N3 query58 실패를 피했지만 N2 query202 완주를 새로 잃었다. B의 선택 결과는 개선12·동률6·악화6이며, 조건부 시간 개선으로 실패를 상쇄하지 않는다. 도로별 B 완주는 O0/O2/N0/N1/N2/N3 각각4/4,4/4,4/4,4/4,2/4,4/4다.

이득 예측 RMSE 자체는 A 1.02587 → B **1.45292**로 악화했고, 여섯 도로 중 N3만 개선했다. 실제 선택과 전체 회귀 오차가 서로 다른 지표임을 보존한다. 추가 이력의 국소 도움은 있었지만 이 고정 선형 predictor의 실패 회피·안전한 선택 근거는 부족하다. 이것은 긴 이력·recurrent 구조 또는 관측 정보 일반의 불가능성을 증명하지 않는다. 표본은 여섯 알려진240 TRAIN 도로의24개 상태뿐이며 296으로의 이전이나 반복 개입은 검증하지 않았다.

저장 필드 해석 오류 두 건을 fit 전에 교정했다. `snapshots`는 sparse pre-query이고 `actual`은 모든 행동 직후 시각이었다. `obs_sha256`도 pre-feature와 함께 저장되지만 행동 직후 픽셀 hash였다. 기존 파일·표적·게이트는 변경하지 않았으며 없는 값을 보간하지 않았다. 여섯 fit 뒤 NumPy 정수의 JSON 직렬화 오류는 저장 모델·예측만으로 복구했다. 76개 입력 열·학습 fold 통계·저장 예측을 독립 재구성했고 normal-equation 잔차는 1.51e−14 이하였다. 복구 추가 fit은0이다.

새 native·source physics·actor 호출·teacher query·PPO·유료 자원은 **0**이다. 신규 history ridge fit은 **6**, current fit·최종 full fit은0이다. 성공한 분석 wall/CPU는 10.13/10.11초, export 복구는 0.90/0.84초다. fit 전 실패 시도의 CPU는 수집하지 못했으므로 전체 시도 CPU 합으로 주장하지 않는다. native 손실과 실패 시도 fit은0이다. 연구 잔여 **395**, 최종 예비 **84,000**, 예산 v331은 그대로이며 비용 원장은 한 번만 기록했다. 개인 원문·픽셀·GT·모델·정확한 예측 배열은 공개하지 않는다.

다음 판단은 이 이력 입력을 더 긴 recurrent/PPO 학습으로 확대할 근거가 없다는 것이다. 두 N2 실패와 현재16 대조의 실패 결과를 함께 남겨 다음 별도 가설의 반증 자료로 사용한다. 이번 고정 이력 모델의 추가 튜닝이나 새 주행은 진행하지 않았다.

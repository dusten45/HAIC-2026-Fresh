# 303 — 목표 소실 조건으로 좁힌 gas guard 파일럿

**후보 0/2, 정확한 296 기준 1/2 완주로 사전 게이트를 통과하지 못했다.** 나머지 16 TRAIN은 실행하지 않았으며, 전체 18개 성적을 추정하지 않았다. champion296과 240 rollback을 유지했다.

301의 변경된 궤적을 이어받지 않고 원래 296에서 시작했다. 같은 호출의 `feature8 == 1 and feature14 == 0 and feature0 == 1`일 때 최종 gas만 0으로 반환했다. feature8은 기존 near flag, feature14는 nominal gas, feature0은 route target 소실 여부다. 마지막 조건은 물리적 도로 부재나 충돌을 뜻하지 않는다. steering·brake·직접 controller memory·모델·계수·perception·head는 보존했다. 이후 관측이 달라지므로 기준 정책의 전체 행동 궤적까지 같다는 주장은 아니다.

실험 전에 T2950/T2954를 한 번씩 공식 종료까지 평가하고, 완주 수가 더 많거나 같은 수에서 공통 완주 평균 시간이 엄격히 짧을 때만 남은 16 TRAIN으로 확장하도록 고정했다. 총 한도는 6,000 native였다. 기준 결과는 300에서 수집한 정확한 296 주행을 재사용했다.

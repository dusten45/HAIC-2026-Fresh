# 474 저장 궤적·제어식 감사

474는 저장 자료와 소스만 분석했다. 새 model tick/world, native action, reset, actor 호출은 모두 0이며 원장도 변하지 않았다. 주 분석 CPU 2.044초/벽시계 2.066초, 독립 기하 재구성 CPU 0.206초였다. 10분 이내 체크포인트를 남겼다. 기존 명시적 연장에 따른 종료 시각은 2026-10-20 19:01:55 KST이며 자동 연장은 없다.

## 확인한 계약과 경계

473 Original/P4와 안전 완주한 472 native P4, 442 native C0/P의 저장 2,654 raw 상태, 665 wrapper를 비교했다. raw 20ms와 명령 유지 80ms를 분리했고, pre-world 휠 힘과 post-world 관측을 같은 물리 시각에 정렬했다. 첫 위반은 Original post321→pre322(9.20초), P4 post202→pre203(6.82초)로 연결된다. 실패 이후 자료는 공통 구간 통계에서 제외했다. 실패 지점은 사후 진단 창 선택에만 사용하며 정책 트리거로 쓰지 않는다.

소스의 cursor와 float32 명목 조향을 독립 산술로 재구성한 결과 665개 모두 오차 0, cursor 불일치 0이었다. 명령/추종식 조향 포화도 없었다. 조향 부호·라디안·3.24m 휠베이스에 명시적 불일치는 없었다. 추종 기준점은 hull origin, 속도는 COM이며 후륜축 기준점과 같지 않다. preview는 clamp(3.24+0.22v,6,25)m다. 기하식 일치는 동적 추종 가능성의 증명이 아니다.

0.8/0.2 명령 필터의 평균 지연 20ms, 관절 서보, 80ms 유지가 별도 요소다. 관절 명령 속도 상한 3rad/s는 실제 응답 보장이 아니다. P4 첫 위반 상태의 관절 목표 오차는 7.45e−8rad인데 heading 오차는 0.477rad, 후륜 횡슬립은 10.569m/s였다. 실패 창에서 횡력 단독 한계 초과가 6.34초, 관절 서보 속도 제한이 6.62초에 나타났다. Original도 각각 8.74초/9.02초 순서다. 따라서 단순 명령 지연을 주원인으로 확정하거나 필터 제거를 승격할 근거는 부족하다.

## 남긴 가설 두 개

1. **기하 추종·preview와 유한 응답/유지의 결합.** 동적 오차에 기여할 수 있지만 부호/단위 오류, 명령 포화, 필터 지연 단독 설명은 지지되지 않았다. 저장 상태에서 필터를 제거한 목표와 실제 관절의 평균 차이는 오히려 커졌다. 이는 새 궤적의 반사실 결과가 아니다. 후륜축 보정·preview 조정·필터 제거 후보는 승격하지 않는다.
2. **종·횡력 할당 경쟁.** 엔진/브레이크로 wheel omega를 바꾼 뒤 종·횡 요구력 벡터를 함께 제한하므로 종력 요구가 횡력을 줄이는 조건부 기전은 소스와 raw에서 확인됐다. 그러나 안전 442에도 clipping이 있으므로 clipping 자체는 실패 충분조건이 아니다. P4 후륜 49개 clipping 중 41개는 횡력만으로도 한계를 넘었으므로 같은 휠 상태에서 종력을 없애도 즉시 해소되지 않는다. 최대 비율이나 사건 순서로 동적 원인을 단정하지 않는다.

곡률·vκ는 저장 polyline 진단값이며 실제 요구 yaw나 타이어 실행 가능성 증명이 아니다. P4 전체 또는 제어 계열 전체의 불가능성을 증명하지 않았다.

## 하나의 조건부 반증 제안

최종 제안은 **조향을 고정한 종방향 할당만 변경**한다. pre23 root, P4 노드·참조·피드백, preview/필터/서보, 유지 시간, 안전·진행·완주 기준을 유지한다. 원래 활성 pedal q0 이하의 유한 float32 값 중 현재 네 휠의 첫 20ms 원래 힘 방정식을 만족하는 가장 큰 q를 선택한다. 반대 pedal은 0이다. gas ramp, omega·브레이크 부호 분기와 실제 양자화를 포함하며 단조성을 가정하지 않는다. 집합이 비거나 최대값을 인증할 수 없으면 중단한다. 실패 위치 pulse나 구조용 제어기는 없다. 첫 raw 순간의 조건부 인증은 80ms 안전 보장이 아니다.

**미구현·정적 게이트 미통과·실행 미승인 상태다.** 다음 최소 게이트는 저장 before-wheel 상태에서 기존 첫 raw 힘을 정확히 재구성하고 q=q0 동일성, pedal 외 불변성, ramp/분기/양자화를 검증하는 읽기 전용 작업이다. 상태 부족·불일치면 종료한다. 최초 필터 제거 아이디어는 증거 조건을 충족하지 못해 선택하지 않았으며 원기록은 보존했다. 기존 static-control audit와 methods380 기록을 검토했지만 원래 개인 방법론 문서 두 개를 직접 읽었다고 주장하지 않는다.

향후 실행을 별도 등록한다면 자격 검사 1,674 tick/47 world를 포함한다. 모델 두 arm은 각각 최대 250회 한 번, 첫 own13 정확 연결 후 own14 이후로 진행한다. 기술 오류는 전체 중단, 물리/영역/진행 실패는 해당 arm 종료, 재수정·재시도는 없다. 새 후보의 안전 own-finish가 후속 게이트다. 기존 P4가 실패하고 후보만 완주하면 안전 회복이며 가상의 완주 시간 이득을 만들지 않는다. native·픽셀·일반화 승격은 별개다. HOLDOUT/SEALED를 열지 않았다.

## 중복 없는 장부와 관측 한계

순서대로 unwrap한 기준 경로의 양의 첫 통과 구간에서 `D=기준 arc 진행`, `d=차체 경계점 사이 chord`, `V=양끝 속도 크기 평균`, `H=양끝(v·차체 정방향·경로 접선) 평균`, `Q=양끝(실제 속도 벡터·접선) 평균`으로 둔다. `τr=∫ds/r268(s)`는 고정268의 제곱 속도 선형 보간을 해석적으로 적분한 참조 시계다.

```
속도 항 A       = D/V − τr
heading 항 Bh  = D/H − D/V
body-slip 항 Bs= D/Q − D/H
경로 metric C  = d/V − D/Q
경계 적분 잔차 R= dt − d/V

dt = τr + A + Bh + Bs + C + R
(d−D)/V = Bh + Bs + C       # 별도 진단값이며 다시 더하지 않음
```

모든 항의 합과 공식 시간 장부를 수치 오차 범위에서 확인했다. 같은 속도 손실을 곡률·슬립·경로 길이에 반복 배정하지 않는다. 종방향 wheel slip 때문에 속도가 떨어진 효과는 이미A에 들어가므로Bs로 다시 더하지 않는다. Bh/Bs는 이 순서의 방향 counterfactual이고, Bs/C는 음수가 될 수 있다. 음수라고 미끄러짐이 유익하거나 추가 단축 여지가 있다고 결론내리지 않는다.

위치와 속도는 저장된 `hull.position`/`hull.linearVelocity`를 그대로 썼고 별도 기준점/연속 운동학 보정은 하지 않았다. 이 식은 **경계 표본의 대수적 항등식**이다. actual raw hull 위치가 없어 진짜 연속 주행 길이를 복원하지 않았다. chord는 길이의 하한 proxy, V/H/Q는 경계 평균이며 R에는 가감속 적분·곡선 표본화 차이가 남는다. C도 순수한 인과적 '불필요한 경로 길이'가 아니라 방향 항을 배정한 뒤 남은 geometry/metric 항이다. 곡률·타이어 과부하가 가능한 속도를 제한하는 동역학 효과는 주로A의 원인 후보이며 이 장부만으로 분리 식별되지 않는다.

# 397 정적 자격과 398 전체 주행 파일럿

출발·사영·결승 경계의 정적 자격은 통과했지만, 동결 후보 C397은 알려진 TRAIN 두 조건에서 모두 사전 등록한 경로 오차 3m 중단 기준을 넘었다. **전체 주행 연구 게이트는 실패했고 후보를 닫았다.** 결과를 본 뒤 gain·profile·중단 기준을 변경하거나 재주행하지 않았다. 새 완주 시간은 측정되지 않았다.

관측 구간은 lap 시간이 아니다. 완주 0, 실제 환경 DNF 0, 안전 중단 2, 기술 오류 0이다. 중단 당시 네 바퀴 모두 도로 접촉을 유지했고 충돌·잔디 접촉은 관측되지 않았다. 연구자가 먼저 멈췄으므로 이후 완주나 DNF를 추정하지 않는다. 비교용 기존 O390 기록은 O0 19.70초 완주·손상0, N1 20.72초 관측 후 실제 off_track DNF·손상0이다. 미완주 관측 시간을 완주 시간과 평균내지 않는다.

397에서는 저장 C 명령 24개, 기록된 출발·양의 진행 전환 각 2개와 정적 fixture 17개가 모두 통과했다. LAUNCH와 정지 의도를 분리했고, FIRST_LAP 목표는 조향 cursor가 아닌 실제 unwrapped arc에서 읽는다. 공유 정점은 고정한 단측 사영을 쓰며 비인접 중복 사영은 거부한다. 임의 epsilon은 쓰지 않았다. 공식 중앙 통과 후보 뒤 전방 끝이 빠져나가야 DONE이며, 시간은 공식 중앙 통과 기록을 쓴다. 이는 계약 자격이다. 이번 실제 주행은 결승 확인 단계에 도달하지 않아 그 단계의 물리적 성능은 미검증이다. 자격 통과 뒤 별도 계획을 먼저 동결하고 두 조건을 reset부터 한 번씩 실행했다. 경로·pace1.5 profile·gain1.5·clamp·pedal map·기존 pure pursuit를 고정했다. 각 제어기는 자신의 현재 실제 상태로 조향과 페달을 갱신했다. 저장된 미래 명령을 강제하지 않았다. 초기 전체 이용 가능 상태와 첫 출발 명령·반응은 기존 O와 정확히 일치했다. 등록 상한은 총1600행동·reset2·CPU180초·wall300초, 예비 사용0이었다. 두 조건 모두 O와 페달·물리 상태가 처음 달라진 것은 23번 행동, 조향은 24번이었다. O0는175번, N1은99번에서 멈춰, 앞서 성공했던 국소 개입 시작점221/161에 도달하지 못했다. 따라서 원래 정책으로 진입한 뒤의 짧은 창 성공은 reset부터 실행하는 전체 정책의 성공을 보장하지 않았다.

실패 행동에서는 두 조건 모두 앞·뒤 바퀴 각각8/8 wheel-tick에서 힘 벡터가 포화됐지만 양의 gas를 요구했다. O0의 종료 yaw rate는4.865rad/s, N1은5.811rad/s였다. 기존 O의 같은 arc를 포함하는 관측 구간은 횡오차와 yaw rate가 더 낮았지만, 같은 전체 상태에서의 인과 비교는 아니다. 현재 스칼라 속도 법칙은 실제 yaw·slip·횡방향 여유를 직접 쓰지 않는다. 종·횡 동역학의 결합과 실행 불가능한 목표 profile을 다음 가설로 삼을 근거이며, 특정 threshold나 gain 변경이 해결한다는 증거는 아니다.

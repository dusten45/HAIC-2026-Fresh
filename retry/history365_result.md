# 365 양성 관측 이력 보존 후보의 캐시 반증

별도 후보 365가 **등록된 캐시 게이트를 통과**했다. 기존 357과 champion 296는 보존했다. 새 시뮬레이션·학습·실제 폐루프 평가는 없으며, **357의 18/18 공식 완주와 retained 지원점 게이트 실패는 그대로 유지**한다. 365에 새 완주 성적을 부여하지 않는다.

365 archive hash는 `65df88a5b2391675e49c3f39259adab0f8a791da5ab58ea620cbe130b0a9ce34`다. 원래 357 hash는 `b03a65de6410b2fa4805eefcd7a5a05ec246fc27843bdc40facc938927e665ad`다. 모델을 포함한 archive의 나머지 멤버는 같고 `support342_logic.py`의 이력 메타데이터와 `nominal238_base.py`의 routing 조건만 바뀌었다. 이는 하나의 변경 개념이다.

새 `positive_history`는 현재 raw 도로 이웃이 양성이거나, **기존 2m dedup에서 유일하게 제거·대체되는 선행점**이 이미 양성 이력을 가졌을 때 true다. 선행점이 여러 개면 이력을 상속하지 않는다. 기존 dedup이 허용하는 같은 프레임 연결도 같은 규칙으로 처리하고 따로 감사했다. 현재 직접 검출(age 0)은 항상 보존하며 retained low 점도 양성 이력이 있으면 routing에 남긴다. 기존 연결 거리·검출기·transport·만료·full hazard 특징·controller·H1은 그대로다. GT·조건명·프레임·UID를 runtime 예외로 넣지 않았다.

실행 전 후보·비교 archive·관측·게이트·최대 호출 수를 고정했다. 저장 범위는 다음과 같다.

| 자료 범위 | 궤적 | 행동 입력 문맥 |
|---|---:|---:|
| 기존 357 검사 집합 | 12 | 2,792 |
| 363의 전체 행동 입력 | 13 | 3,810 |
| 358–362의 나머지 실제 357 관측 | 5 | 1,538 |
| 합계 | 30 | 8,140 |

공유 prefix와 T2954 같은 중복 관측을 포함한 문맥 수다. 독립 사례나 새로운 30회 주행으로 세지 않는다. 종료 후 마지막 관측은 저장 원본에 남아 있지만 새 정책 행동이 실행된 입력이 아니므로 추가 행동으로 재생하지 않았다.

전수 메타데이터·tracker 재구성에서 알려진 fixture 지원 직접 검출 **1,826개 문맥**, 출생 지원 retained **591개 문맥**의 누락은 각각 **0**이었다. 출생 GT가 없는 직접 12개·retained 16개 문맥은 unknown으로 남겼다. GT 원형 대응은 실행 후 감사에만 사용했고 후보 actor에는 전달하지 않았다. 의미적 재질·가림 정답을 가진 것으로 취급하지 않는다.

T29510에서는 58의 road 이웃 4픽셀이라는 양성 관측이 기존 연결을 통해 59로 보존됐다. 출생 59의 low 플래그는 그대로 true지만 `positive_history`가 true이며, **60–63의 지원 retained 점이 모두 routing에 보존**됐다. 직접 검출 보호도 유지했다.

양성 이력 전파는 **1,677개 연결 문맥**을 조사했다. 서로 다른 것으로 확인된 지원 fixture 사이의 전이는 0이며, 같은 프레임 양성 전이도 0이다. 이력이 현재 low 출생에 들어간 5문맥은 모두 같은 지원 fixture에서 왔다. 이 수에는 T2954의 동일 관측 중복이 포함된다.

한편 **62개 전이는 GT 누락 또는 unresolved 라벨 때문에 물체 정체성을 확정할 수 없었다**. 이 62개는 모두 현재 출생 자체의 도로 이웃이 이미 양성이어서, 이번 저장 자료에서 상속 이력 때문에 low retained 점을 새로 구제한 사례는 아니다. 이를 잘못된 전파가 없다는 일반적 증명으로 삼지 않는다. 2m dedup은 물체 ID가 아니며, 앞으로 모호한 연결 뒤에 low 관측이 생기면 잘못 보존할 가능성은 남는다. GT가 불명확한 점을 거짓 장애물로 단정하지 않았다.

사전 감사에서 실제 routing 포함이 달라지는 궤적은 T29510 하나였다. 이 궤적과 N2 필수 세 궤적을 쌍으로 actor 재생했다. 나머지 26개 궤적·7,130입력은 모든 입력에서 routing 집합이 같고 다른 정책 계산이 바뀌지 않는다는 소스·메타데이터 귀납으로 다뤘다. 이를 새 actor 출력 검사로 표시하지 않는다.

| 실제 쌍 재생 | 입력/arm | routing 차이 | 경로·목표·전체 제어·기억 차이 |
|---|---:|---|---|
| N2_337 | 233 | 없음 | 없음 |
| N2_340 | 233 | 없음 | 없음 |
| 363 T29510 | 252 | 60–63에서 지원점 보존 | 없음 |
| 실제 359 N2의 저장 입력 | 292 | 없음 | 없음 |

각 baseline actor는 해당 동결 357의 기존 경로·특징·전체 제어·audit·tracker·지원 기록·정상 기억·원래 상태 투영을 먼저 재현했다. variant의 메타데이터와 실제 routing 집합도 사전 감사와 맞췄다. 반환한 전체 제어와 정상 기억을 사용한 **고정 관측 재생**이며 새 폐루프 성적이 아니다. 코드 정체성을 담는 full agent pickle digest는 교차 후보 상태 투영에서 제외했고 나머지 정책 상태를 비교했다.

N2의 유용했던 UID 121:0은 127–129에서 age 6·7·8로 계속 제외됐다. 두 N2 고정 입력 궤적에서 기존 357의 출력·기억 전체가 그대로였다. 같은 입력의 과거 무필터 342 기록과 비교하면 경로 차이는 127–129, 목표 차이는 128–129이며 첫 전체 제어 차이는 127, 첫 조향 차이는 128로 유지됐다. 이는 이번 variant actor의 실제 캐시 호출과 자격을 확인한 저장 무필터 출력의 비교이며 새 무필터 actor나 주행을 실행한 것이 아니다. 독립적인 조향·페달의 폐루프 인과 효과나 새 lap 개선으로 해석하지 않는다.

T29510의 252개 고정 입력에서도 경로·목표·특징·전체 제어·audit·정상 기억·원래 상태 투영 차이는 없었다. 60–63 지원점 보존은 실제 actor routing 기록으로 확인했다. 이 결과를 실제 365의 완주로 옮기지 않는다.

호출은 **act 2,020회·commit 2,020회·저장 관측 reset 8회**다. 총 1,010입력을 두 후보로 재생했다. 등록한 최대 14,038 act·48 reset 안에서 필요한 기계적 선택만 실행했다. 별도 clone·standalone routing/target 진단 호출은 0이며 actor 내부 routing 계산은 포함돼 있다. 전수 감사의 old/new 메타데이터 업데이트는 각각 8,140회다.

실행 벽시계 **66.873초**, runner CPU **54.336초**, actor CPU **22.024초**다. 코딩·archive 생성·등록·마감·git 전체 시간은 아니다. 새 wrapper 행동·환경 reset·보조 물리·학습·유료 자원은 모두 **0**이다. 연구 잔여 **22,190회**, 최종 예비 **84,000회**, 누적 wrapper 행동 **1,291,215회**를 보존하며 v381과 비용 원장에 기록했다. 오류나 추가 튜닝은 없었다.

남은 한계는 unknown GT, 관측되지 않은 가림, dedup의 물체 병합, 반복 연구에 사용한 알려진 입력이라는 선택 편향이다. 365는 이 저장 집합에서 확인 가능한 반례를 통과한 연구 후보이며 일반 안전성·공식 성능·승격 근거가 아니다.

최소 후속 계약은 **별도 지시가 있을 때** 동결 365로 T29510 한 번을 자체 관측·전체 제어·정상 기억으로 실행하는 것이다. 기존 초기 조건과 역사적 357을 확인하고, 기존 연구 잔액 안의 최대 2,000행동·공식 종료·현재 승인 종료 시각 중 먼저 닿는 조건에서 멈추며 직접/retained 보존과 양성 이력 전이를 감사하는 범위를 제안한다. 이번에는 예약·실행·자동 연장을 하지 않았다. 향후 반례가 나오면 추가 튜닝 없이 해당 저장 연결만 actor/native 0으로 점검하는 최소 계약을 우선한다.

기존 357·champion 296·main·공식 Participants·기존 사용자 변경과 백업을 보존했다. 새 DEV/HOLDOUT/SEALED 개봉·자동 승격·추가 실험은 없다. 원본 관측·GT·seed·모델·개인 문서는 비공개로 두고 일반 코드와 집계 결과만 기존 연구 브랜치에 기록한다.

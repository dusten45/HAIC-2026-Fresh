# Saved connector reopening gate

Run `python -m retry.saved_connector_reopen_gate --plan PRIVATE_PLAN_JSON`.
The command uses saved event windows and standard-library arithmetic only. It
does not import a participant, simulator, learning framework or replay tool.

Use one previously fixed predicate on both contact cases and selected no-contact
controls: the origin-to-first-grid segment's minimum distance to the routing
obstacle inputs, minus their radius and the existing radial routing margin. The
route and those obstacle inputs are legal intermediate values actually produced
inside the recorded policy decision. The derived margin was not an implemented
risk flag in the frozen policy. Physical states, collision labels and eventual
completion are evaluation labels, never features for this predicate.

The latest supplied pixel frame comes from the previous wrapper's final raw
render. Route computation and action selection occur before the next wrapper's
first raw step; simulation time remains fixed while CPU work and IPC run. The
same action is applied throughout that wrapper. Intermediate raw renders are not
new observations or decision opportunities. A value obtained after an action
starts cannot be assigned retrospectively to that action's pre-application slot.

Count the current decision when its legal intermediate values exist before
application, then subsequent complete wrapper decisions before the contact
interval. Report the inclusive count and the additional decisions after the
first signal separately. Contact time is bounded by its original raw interval.
This establishes availability of a potential computation, without establishing
achievable braking, steering response or prevention.

The saved-case check found the fixed signal in both contact and no-contact
windows. Its short temporal lead therefore does not provide a discriminating
reopening premise. Window anchors and coverage differ, and the controls were
selected for an already observed signal; the result is not a population accuracy
estimate. Missing earlier episode history remains unknown. No new threshold,
policy feature implementation, intervention or preventive-effect claim follows
from this check. Reopening needs new evidence rather than reinterpretation of
the same positive marker.

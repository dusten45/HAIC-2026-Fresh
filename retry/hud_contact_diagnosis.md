# HUD 페달 피드백: 첫 접촉 진단 (118)

기존 DEV 기록의 첫 접촉을 분석하고, 동일 prefix 뒤 페달 피드백 하나를 바꿔 국소 기여를 확인했다. **113 챔피언과 동결한116 후보는 유지한다.**

저장 입력1,250개의 행동이 원본과 정확히 일치했다. 접촉 직전 표본을 도로 진행 위치로 맞추면 차이는3.9cm이며, 후보/챔피언의 차체–장애물 간격은0.204/0.533m였다. 속도뿐 아니라 위치·방향·경로 target·조향도 달랐고 장애물은 계속 추적됐다. 첫 손상 이전의 차이와 접촉 후 손상 영향을 구분했다.

저장 관측에서 후보가 가속하지만 원래HUD라면 제동하는 지점을 선택했다. 실행 전에 **177번째 행동부터 페달 피드백만 원래HUD로 교체**, 양쪽 최대300행동을 등록했다. 두 실행은 처음부터 reset했고176행동·관측·물리 상태가 같았다. 대조군300행동 전체도 기존 기록을 재현했다.

| 측정 | 동결 후보 대조군 | 국소 원래HUD 페달 |
|---|---:|---:|
| 접촉 표시 wrapper 수 | 3 | 0 |
| 동일 장애물 통과까지 손상 | +0.6 | 0 |
| 장애물 뒤10m 진행 기준 통과 | 확인 | 확인 |
| 통과 기준 도달 시간 차이 | 기준 | 약+0.48초 |

세 접촉 표시는 독립적인 세 사고를 뜻하지 않는다. 국소 변경으로 접촉 없이 실제 통과했으므로 단순 정지로 설명되지는 않는다. 다만 이후 관측·경로·조향 변화는 하류 효과이며 경로 계획의 독립 원인을 분리한 결과는 아니다. 두 실행 모두300행동에서 끝냈으므로 전체 완주·랩 개선을 주장하지 않는다. 표본 차체 간격도 일관되게 늘어난 것은 아니며 raw contact/impulse는 저장되지 않았다.

실제 계산은 native600행동24.41초, 저장 정책1,250호출9.94초였다. 준비 약6.1분과 기존 기록 분석·반사실적 준비 약6.0분이 더 컸다. 기존 실행기와 검증 결과를 재사용했으며 이번 변경·prefix·결과만 확인했다.

B682,000은 그대로이며 누적590,560, 연구 잔여7,440, 최종 reserve84,000(사용0)이다. 잔여행동은 연구 종료 기준이 아니다. 현재 실측은 약24.58행동/초다. 다음 캠페인의 N과 실제 세션·준비시간을 정한 뒤 필요하면 `B >= 누적 native + 84,000 + N`을 실행 전에 기록한다. 남은 승인시간 전체를 연속 가동으로 가정하지 않는다.

다음 실험 하나로 **기존 근접 장애물 조건에서만 원래HUD 페달을 쓰는 후보**를 제안한다. 새 임계값·게인 없이113/116/신규 후보를 신규 DEV2조건에서 비교하면 최대12,000행동, native 약8.1분이다. 이 경우 현재 기준 B686,560이 필요하다. 변경 경로 검증과 조건·판정 사전등록 후 실행하며, 기존 완주 우선·시간 판정과 별도 손상 경고를 유지한다. 118에서는 이 다음 실험을 실행하거나 예산을 증액하지 않았다.

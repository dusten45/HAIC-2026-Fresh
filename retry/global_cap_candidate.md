# Stage95 — 계수 7에서 전역 상한 40 후보 한 번

기존 DEV75-1의 계수 7·상한 28 전체 기록을 역사적 기준으로 재사용하고, **계수 7·상한 40 후보 한 episode만** 실행했다. 후보는 **271/271 완주, 55.060초, 손상 0, 접촉 0**이었다. 비교 가능한 기준 59.560초보다 **4.500초 빨랐다**. 이 알려진 DEV 조건의 결과이며 반복성·다른 기하의 보존·챔피언 승격은 아직 판단하지 않는다.

## 비교 가능성과 후보 동결

Stage91의 59.560초·손상 0 기준은 전체 프레임·행동·학생 마스크까지 이미 재현된 실행이다. 당시 등록한 소스 47개와 참조 14개의 해시, 기준 artifact 12개의 등록 해시를 이번에 다시 확인했다. 전체 trace 745행·행동·746개 프레임/마스크의 일관성 및 공식 종료도 검산했다. 초기 full4 관측·물리 상태·도로 기하·실제 장애물 해시와 seed/RNG 구성, native horizon·관측·랩·완주·손상 계약을 고정했다.

기존 동일 worker와 NumPy 1.26.0으로 **저장 관측만** 재생했다. 745개 행동, 746개 학생 마스크와 경로·추적·목표·제어 진단이 모두 정확히 일치했다. 이 검사는 6.226초, actor CPU 5.002초, 정책 act 745회·reset 1회, 학생 추론 746회였다. 환경 reset·step은 0이며 새 기준 episode를 실행하지 않았다. 후보 실제 reset에서도 초기 full4 관측·전체 물리 상태·도로·장애물이 기준과 정확히 같음을 첫 행동 전에 확인했다.

원 기준 ZIP은 그대로 두고 별도 비공개 ZIP에서 두 숫자만 변경했다. `agent.py`가 controller에 전달하는 전역 상한 28.0→40.0과 `champion_distance_cap.py`의 거리 상한 sentinel 28→40이다. 나머지 ZIP 멤버 13개는 byte exact다. 기존 학생 모델·21개 특징·삭제 전용 마스크·속도 추정·근접 곡률 5/비근접 7·age0 거리 공식·경로·추적·조향·제동 식·메모리는 그대로다. 계수 7 래퍼는 무변경 경로이며 cap assertion만 28→40으로 정합시켰다. 곡률 계수와 gate를 함께 바꾸지 않았다.

최대 2,000행동 후보 한 번, B646,000·연구 잔여 3,427·예약 84,000, 정상 raw horizon 8,200을 실행 전에 고정했다. baseline/hash/캐시 재생 실패나 실제 reset 계약 불일치면 후보 행동 전에 중단하며, 후보의 native DNF·비용 검열·기술 오류는 유지하고 자동 재시도하지 않는다. 정상 종료 없이 2,000행동에 도달하면 자원 검열이지 native DNF가 아니다. 공통 완주에만 랩 차이를 계산하고 손상은 별도로 보고한다. 최소 랩 이득 문턱과 자동 승격은 없다.

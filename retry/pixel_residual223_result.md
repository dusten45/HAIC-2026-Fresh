223 — DEV 교사 기록의 적법 픽셀 잔차 학습 가능성 점검

**필수 관측 자료가 없어 학습 전 게이트에서 중단했다.** Native 0회·모델 질의 0회·학습 업데이트 0회이며 leave-one-road-out 비교와 학생 추론 비용은 미측정이다. 미측정을 0ms 또는 모방 개선으로 해석하지 않는다.

| 알려진 DEV | 교사 실행 명령 행 | 저장 픽셀 관측 | 챔피언 재생 자격 |
|---|---:|---:|---|
| F0 | 368 | 0 | 미충족 |
| F1 | 334 | 0 | 미충족 |
| F2 | 337 | 0 | 미충족 |
| F3 | 353 | 0 | 미충족 |

빠진 자료는 reset 입력과 각 act 입력의 순서가 보존된 실제 float32 `(4,84,84)` 관측이다. 관측열 SHA-256은 있지만 픽셀을 복원할 수 없다. 기록된 이전 이미지·hazard 기억·controller steering 상태를 포함한 현재 normal24 챔피언의 인과적 상태 재생도 검증할 수 없다. 관측 이력이 있으면 reset부터 재생하여 상태를 만들 수 있으므로 모든 상태의 별도 snapshot을 필수로 요구하는 것은 아니다.

교사 실행 명령 1,392행과 GT 물리 진단·일부 경계 snapshot은 남아 있다. 그러나 해당 관측에서 **현재 적법 챔피언이 반환한 특징과 명령**은 없다. 221의 `nominal_action`은 normal32 actor가 교사의 실행 steering을 피드백받은 결과여서 normal24 챔피언 입력·명령으로 대체할 수 없다. GT로 픽셀이나 특징을 재구성하지 않았다. 교사와 챔피언의 상태 차이별 오차 역시 측정하지 않았다.

근거: [평가기](frozen_paired_evaluation.py)는 관측을 hash에 누적하고 저장 프레임·정책 telemetry 행을 0으로 기록한다. [GT supervisor](receding_horizon_oracle.py)는 actual action과 nominal action을 저장하지만 실제 픽셀 입력열과 normal24의 인과적 특징열을 저장하지 않는다. 기존 DEV 221 디렉터리의 파일 목록과 JSON schema를 확인했으며 220·222 HOLDOUT와 SEALED 자료는 사용하지 않았다.

[재현 가능한 읽기 전용 점검 코드](pixel_residual223_audit.py)는 `--records PRIVATE_STAGE221_DIR`로 실행한다. 지정 클라우드에서 점검 wall **0.270초**, CPU **0.259초**였다. 학습 데이터·head·학습률을 정하거나 sweep하지 않았다. [익명 결과](pixel_residual223_result.json)에 누락 항목과 미측정을 구분했다.

챔피언을 유지했고 native 누적 745,651회·연구 잔여 2,349회·예비 84,000회 미사용으로 변동 없다. main·Participants·백업·사용자 변경을 보존한다. 이번 요청은 저장 자료만 허용하므로 새 관측 수집이나 자동 후속 실험을 시작하지 않는다. 향후 학습의 선행 조건은 알려진 DEV 교사 실행의 실제 관측 이력과 현재 챔피언의 정확한 인과적 재생 자료 확보다.

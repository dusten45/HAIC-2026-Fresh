# 299 — steering gain의 log-space 중점 한 개 검증

**고정 중점 후보는 18 TRAIN에서 15/18 완주로, 296의 17/18보다 낮아 탈락했다.** 공통 14도로에서는 평균 0.715714초 빨랐지만 전체 완주 수가 적어 다음 평가에 부적격이다. 봉인 DEV 12개는 열지 않았고 champion296과 240 rollback을 유지했다.

296의 steering curvature gain과 240의 원래 gain 사이 log-space 중점 한 개만 고정했다. 240 상대 log 좌표를 `theta_steering/2`로 정확히 반분하고 패키지의 gain factor는 `exp(theta_steering/2)`로 만든다. 이는 수학적으로 두 gain의 기하평균이다. 실제 float64 계수·원계수·source/hash·패키지 hash와 판정 규칙은 첫 결과 전에 비공개 freeze 기록에 저장했다. 원래 steering 계수 하나 외에 나머지 다섯 실제 값과 perception·head·feature 계산·memory 구현은 그대로다. 다른 중간값·조합·재튜닝은 없다.

고정된 18 TRAIN 전부에서 같은 한 후보를 한 번씩 공식 종료까지 평가했다. 296의 기존 결과는 재사용했다. 완주 수가 더 많거나, 같으면서 공통 완주 도로 평균 공식 시간이 엄격히 짧아야 적격이다. 그 외에는 종료하며 개별 도로 손실과 damage는 별도 veto가 아닌 진단이다.

중점 후보는 T2950을 추가 완주했지만 T2954/T29510/T29511의 기존 완주를 잃었다. 자체 평균은 서로 다른 완주 집합에서 계산한 조건부 시간이며, 공통 시간도 실패 도로를 제외한 값이다. 이를 전체 18도로의 속도·완주 개선으로 표현하지 않았다. 완주 수 15<17이 사전 탈락 이유이며 특정 도로 하나의 손실을 별도 veto로 사용하지 않았다.

297에서 등록한 미개봉 DEV 12개를 이번 평가로 넘긴 identity와 봉인 기록은 새 결과 전에 고정했다. TRAIN gate 탈락으로 DEV는 열지 않았고, 다른 중간값이나 298의 다른 후보로 교체하지 않았다. 298의 원결과도 그대로 보존했다. 이 한 고정 후보에 대한 결론이며 다른 중점·방법군·전체 목표의 불가능성을 주장하지 않는다.

검증은 log 좌표의 정확한 반분과 기하평균 관계, 다른 다섯 실제 값 및 나머지 ZIP 모듈 보존, source/hash 사전 고정, 18개 공식 결과와 gate 산술, trace와 charged native 일치, 프로세스 회수와 compile을 확인했다. 실행되지 않은 조건부 승격의 metadata 참조 경로를 사전 midpoint freeze 파일로 정리했으며 실행 원본 source와 수정 hash를 별도 기록했다. 정책·판정·결과는 바뀌지 않았고 추가 호출은 없었다.

실제 비용 **4,896 native = TRAIN 4,896/6,000 + DEV 0/9,000**이다. 기술 오류·검열·미실행·재실행은 0이다. 전체 실제 wall 211.604초, episode runner CPU 합계 210.554초, 별도 actor CPU 47.447초다. 병렬 episode wall 합계 265.762초는 전체 경과시간과 다르다. raw step 19,564/reset 918 tick, source model physics·유료 자원은 0이다.

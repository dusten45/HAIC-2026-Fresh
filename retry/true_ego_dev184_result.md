184 — 정답 ego-motion으로 기존 추적 좌표만 전파

**접촉 전 추적 오차를 없앴지만 첫 접촉과 미완주는 남았다.** 183에서 구제된 도로는 유지됐고, 남은 실패는 구제되지 않아 완주는 여전히 1/2다. normal24 챔피언을 유지한다. 이 버전은 정답 정보를 쓰는 연구용 진단이며 제출·승격 후보가 아니다.

183 중심·반경 adapter와 181 normal32 ZIP을 고정했다. 이전에 저장한 대상 좌표에 이전→현재 차량 pose의 이동·회전만 적용했다. motion 입력에는 장애물 정답 좌표·ID·새 대상·가림 정보·미래 pose가 없다. 검출·연결·생존기간·개수를 분리하기 위해 원래 임시 예측과 기존 연결/생존 규칙이 남긴 같은 순서의 목록을 유지하고, 이어진 대상의 좌표만 교체했다. 나이·반경·새 검출값은 그대로다. 이후 상태와 주행이 달라져 미래 목록이 달라지는 것은 구분한다. 도로·32/8/45·경로 선택식·조향·페달은 고정했다.

183의 마지막 현재 검출은 행동 57, 무검출 입력은 58~62였고 첫 충돌은 62행동 뒤였다. 저장한 정적 GT 좌표계 대응의 SE2 산술 검사는 오차 2.79m를 수치 오차 수준으로 줄였다. 이 저장 검사는 부품 산술이며 성능 증거가 아니다. 실제 실행에는 차량의 이전·현재 pose만 사용했다. 오래된 132의 접촉 후 결과는 새 근거로 사용하지 않았다.

normal24 최초 접촉은 기존에 기록되지 않아 추가 재현하지 않았다. 위 시간은 native 경과 시간이며 공식 lap이 아니다. 도로 2의 183·184 첫 접촉은 같은 장애물이다.

실제 좌표 개입은 retained 항목 기준 도로별 **283회·108회**였다. 최초 접촉 이전 입력에서 좌표가 바뀐 행동은 141회·13회, 그중 현재 검출이 없는 행동은 80회·5회였다(무접촉 도로 1은 전체 구간). 도로 2의 행동 57~62에는 단일 대상만 남았고, 58~62는 새 검출 없이 age 1→5였다. 이 실제 구간의 오차는 모두 1e−9m 미만, 접촉 입력 62에서는 약 **8.95e−16m**였지만 그대로 접촉했다. 접촉 후에만 오차가 줄어든 경우는 아니며, 정확한 전파만으로 첫 접촉을 막지도 못했다.

현재 중심 치환 규칙은 그대로이며 실제 교체는 120회·79회, 최초 치환은 이전과 같은 행동 37·41이었다. 원래 같은 입력·상태의 연결/생존 목록 대비 개수·순서·나이·반경·새 검출값 보존과 실제 SE2 적용을 모든 행동에서 확인했다. 목표/P 법칙·입력/행동 hash·초기 상태·actor 회수도 통과했다. 빌더의 들여쓰기 오류는 worker·정책·native 실행 전 수정했고 비용은 0이었다. 별도 자격 검사는 reset 2회·act 4회였다.

새 native **739/4,000회**, raw step **2,953틱**·reset **102틱**이다. 새 prefix나 기준선 전체 재주행은 없다. 실행 wall **55.801초**, evaluator CPU **50.559초**, actor CPU **8.673초**이며 준비·자격 검사·저장 산술·게시는 제외했다. **B800,000 = 누적707,953 + 연구8,047 + 예비84,000(사용0)**.

현재 결과는 합법 ego-motion 추정만 해결하면 된다는 결론을 지지하지 않는다. 기존 연결·생존 결정을 고정한 부품 진단이므로 전체 추적 oracle도 아니다. 정확한 위치에서도 남는 경로·차체 경계·추종의 관계는 미해결이며 유일한 원인은 주장하지 않는다. 추가 실험 없이 닫고 새 HOLDOUT·SEALED, 현재 챔피언·main·Participants·백업과 비공개 자료를 보존한다.

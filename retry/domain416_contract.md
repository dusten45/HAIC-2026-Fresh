# 416 사전 정적 계약 — 실행 정책은 변경하지 않음

검사 대상은 기존 C 식 `a=f*(sigma/r)+1.5*(r-v)`, `sigma=velocity·(edge/|edge|)`, squared-speed 보간 `r>0`이다. 이 식은 r>0에서 sigma의 모든 유한 실수 값에 수학적으로 정의된다. sigma=0에서는 f 항이0, v=0이면 a=1.5r>0이다. ±미소 sigma에서 연속이며 음수라는 이유만으로 대수 정의역에서 제외할 필요가 없다. 실제 의미 있는 후진에 대한 기존 `sigma<−0.1m/s` 또는 차체 forward velocity<−0.1m/s 안전 중단은 그대로 유지한다. 이 물리 기준은 기존390/413의 명시적 조건이며 부동소수 오차 허용치가 아니다. 작은 음수도 signed 값 그대로 대입하고, epsilon·round-to-zero·clip·새 gain을 넣지 않는다. 현재 executor의 엄격한 `sigma<0` 거부와 이 정적 제안의 차이를 계수하되 실행 파일은 바꾸지 않는다.

입력의 수치 층을 분리한다. Box2D pose/velocity는 binary32이고 Python float로의 승격은 정확하다. 저장 path와 profile은 binary64이며 JSON float는 원래 binary64 값으로 읽는다. 실제 projection/edge/norm/내적과 C 식은 NumPy/Python binary64, 마지막 action은 binary32다. 실제 속도 잔류값·solver/입력 표현 오차를 내적 평가의 반올림 오차라고 부르지 않는다. 입력 velocity의 binary32 roundtrip과 기록 속도 norm을 검사하고, 표현 cell의 half-ULP 범위는 가능한 입력 반올림 범위일 뿐 정확한 물리 상태 오차 인증이 아님을 밝힌다.

정상·유한·overflow/underflow 없는 두 차원 계산에서 DAG는 edge 차분2, 제곱2+합1+sqrt1, 접선 나눗셈2, 내적 곱2+합1의11연산이다. unit roundoff u=2^-53, gamma_n=nu/(1-nu)로 둔다. edge는 componentwise relative error≤u, norm의 relative error≤gamma_6, normalized component는 `(gamma_2+gamma_6)/(1-gamma_6)≤gamma_10`, 내적의 두 곱·합은 gamma_2 오차이므로 최종 absolute error는 보수적으로 `gamma_16 * sum(|v_i*t_i|)` 이하로 잡는다. 입력값을 이미 정확한 binary64 실수로 볼 때의 계산 오차다. dot에 FMA를 사용하면 연산 수가 줄어 이 상한을 악화시키지 않는다. 결과에서 역으로 정한 허용치가 아니다. subnormal/0/극단 입력에는 이 상대오차식을 적용하지 않고 각 연산을 양쪽 `nextafter`로 외향 반올림하는 interval DAG를 사용한다. interval은 부호 모호 여부를 판정하기 위한 진단이며 sigma 값을 바꾸는 장치가 아니다.

독립 검증은 Decimal 100자리로 정확한 binary 입력의 edge·내적·sqrt를 다시 계산한다. 내적의 부호는 sqrt 없이 Fraction 정확 유리수 numerator로도 확인한다. 연산 상한/interval 포함 실패, 기존 식/기록 normal C pedal 불일치, 비유한 또는 보호 hash 실패면 정적 단계를 중단한다. fixed corner tests는 r=2,f=−3, sigma=velocity의1D식에 대해 0, ±2^-40, ±1, ±최소 binary64 subnormal, r=0을 사용한다. 분명한 후진 안전 분류는 유지한다. r=0에서는 positive-target C 식을 정의하지 않고 기존 LAUNCH/STOP/FINISH_CONFIRM/DONE 계약을 유지한다. 새 분모 epsilon이나 출발 fallback을 만들지 않는다.

segment 내부에서는 `dr/dt=f*sigma/r`가 squared-speed profile에 대한 chain rule이다. vertex에서 경로 접선과 f는 일방 값이며 단일 양측 도함수가 일반적으로 없다. current canonical projection의 outgoing-node 규칙과 FIRST_LAP/FINISH_CONFIRM의 node0 incoming 규칙, distinct/nonadjacent tie 거부를 유지한다. 양쪽 raw 차이는 같은 positive r,v에서 `(f_R*sigma_R-f_L*sigma_L)/r`다. 정지 v=0이면 양쪽 sigma0에서 이 차이가0이다. 출발/결승 seam은 비주기 속도 노드 때문에 r 자체가 달라질 수 있으므로 phase를 무시한 주기화는 하지 않는다. 고정 저장 경로 모든 노드에서 stationary·forward·reverse 양측 식과 pedal을 비교해 기존 불연속과 미정의 구간을 보고한다.

# 552 — 정상 retiming의 고정 제동80을 반증한 source 상태 의존 제동 증거

새 주행 후보를 먼저 만들지 않고 저장541/551 전체를 분석한 뒤 **source 상태 의존 제동 도달가능성** 하나를 선택했다. 단일 사전 등록 반증에서82.17→50.03m/s 감속을 전역 안전과 기존551 참조를 지키며 수행했다. COM 이동거리·source 적분 방식·기존 오차 여유를 맞춘 뒤에도 source 제동거리 상한 **13.4185m**가 고정80m/s² surrogate 하한 **25.9853m**보다 **12.5668m 짧았다.** 이 rigid source 모델의 이 관측 상태에서는80이 필요한 물리적 제동 한도가 아니라는 양성 증거다.

이는 **새 랩 시간 이득이나 늦은 제동 정책의 검증이 아니다.** 실제 기준13.66초,551의 source13.22초/440ms·500ms 미달, carry/native 미실행을 그대로 유지한다. 제동 지연으로 상태가 바뀌면 이 제동 능력도 바뀐다.80을 새 단일 상수로 교체하거나 결과를60ms 회수·전체 랩 시간으로 환산하지 않았다.

이 노출 시간은 회수 가능한 시간이나 독립 표본 수가 아니다. 참조 때문에 일찍 중단된 HIGH 보고는 이후 힘/geometry가 미관측이다.551의 reference 거절56개 중40개가 중단 시점까지 peak<.7이었지만, 이를56개 물리적으로 안전한 전체 분기라고 세지 않는다.551에서 비상한·낮은 힘 노출은 이미.12초로 줄었다. 단순cap/gain 변경이나 남은60ms를 채우는 참조 상승을 선택할 근거로 쓰지 않았다.

정상 분담 기대값과 source의 실제 휠 횡력도 다르다. force **전 상태**의 속도·station·joint/heading/rotational offset을 맞춘 비교에서, 휠별 최대 차이의 중앙값/95백분위는541 **79.15/224.79N**,551 **84.41/254.46N**였다. 보수적 인접 최대 곡률 처리·다른 실제 궤적·yaw/조향/휠 과도 상태가 함께 만드는 차이이며 source 예측오차나 그만큼 풀어도 되는 힘 여유가 아니다. source 실제 yaw 토크도551의 **566개 tracking raw**에서 중앙값59.71·95백분위531.12N·m로 변한다. 정상 무각가속 배분만으로 이 응답을 표현하지 못한다.

초기552 횡력 통계는 before-force에 after-step speed/station을 혼용했다. 원본을 보존하고 감사에서 pre-force 상태로 다시 정렬한 위 값으로 정정했다. clipped 적용 횡력과 source 미clip 횡력도 따로 확인했다. 중단 사유·root 선택·제동 실험·문턱은 이 정정에 의존하지 않았고 바꾸지 않았다.

19개 동일 pedal 대수 평가를 저장된 각 before-hold 상태에 적용했다.551142상태에서 즉시 force-admissible 표본의 최소 가속도는−219.12~−7.28m/s²(중앙값−110.99), 최대 가속도는.20~41.58m/s²(중앙값18.78)로 달랐다. 이는 유한 grid의 **순간 derivative 범위**이며 연속 최적값·4tick 이상 지속 능력이 아니다. 바로 이 차이를 실제 여러 tick의 안전 응답으로 검증할 필요가 있었다.

## 작은 사전 반증과 결과

실행 전에 최대16hold·50,000모델틱·명시 힘250,000회·geometry60,000회·CPU900초/wall1,100초를 등록했다. brake-only actuator 범위에서 기존537 grid/lock 경계와 최대9회 경계 세분화, hold당 최대32번 source 인증으로 **첫 hold 끝 속도가 가장 낮은 feasible 행동**을 고르는 설계용 oracle이다. 조향은 매 hold 새로 계산했고 원53712hold certifier/551참조/backup을 유지했다. 이는 racing 정책이 아니라 제동 도달가능성의 witness 생성기다.

## 후속 구조와 승격 경계

이제 근거 있는 후속 구조는 **각 진입 full state에서 source 제동 도달가능성을 다시 전파하는 동적 retiming**이다. 한 상태에서 얻은13m 또는 평균 감속률을 전체 경로의 고정 상수로 쓰면 안 된다. 더 늦게 제동하면 omega·가스 기억·joint·yaw·접촉과 힘 예산이 달라진다. 후속 단계는 진입 상태와 제동 전환 경계를 연결하고, 고정된 한 profile/정책을 작은 폐루프 반증으로 확인하는 것이다. 현재552에서 새 주행 candidate/전체 모델/실제를 자동 실행하지 않았다.

551의60ms 부족을 메우려 문턱을 낮추거나cap/gain을 조정하지 않았다. 향후 성능 승격은 source cold≥500공식ms 개선 vs54113.66·carry 전안전/14.46 대비 비악화·그 뒤 새 실제쌍≥500ms와 기존 force oracle/onehold 예측·실제 안전을 요구한다. 조건부 실제 상한은1000행동/2resets/2worlds/4102raw 이내로 유지하지만, 이번 설계용 probe의 실제 상한은0이고 사용도0이다.

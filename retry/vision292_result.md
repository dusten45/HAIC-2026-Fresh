# 292 — 고정 시각 예측기의 6도로 leave-one-road-out 비교

**전체 RMSE와 부호 정확도가 악화해 큰 픽셀 PPO로 승격하지 않는다.** N2 등 일부 개선은 그대로 기록하며, 영상 정보 일반의 불가능성이나 통계적 유의성을 주장하지 않는다.

291의 동일한 12개 TRAIN episode를 재사용했다. 각 도로의 두 episode 전체를 test로 제외하고 다른 10개만 학습·정규화에 사용했다. 기존 N2의 모델·예측·분할·원 코드 hash를 검증해 두 fit을 재사용하고 나머지 다섯 fold의 두 모델씩만 새로 학습했다. 28 MLP(4,501 parameter)와 pixel+28 CNN(4,473 parameter), 영상 처리, episode 균등 정규화·loss, seed, Adam, 20 epoch, 마지막 checkpoint 고정은 모두 291과 동일하다. 도로·GT·정책·episode ID와 미래 frame은 입력에 없다.

| 제외 도로 | 28 RMSE | pixel+28 RMSE | MSE 변화(pixel−28) | RMSE 개선 |
|---|---:|---:|---:|---:|
| O0 | 0.944090 | 0.954824 | +0.020382 | -1.137% |
| O2 | 0.955998 | 0.962102 | +0.011707 | -0.638% |
| N0 | 1.078359 | 1.125230 | +0.103286 | -4.347% |

각 도로가 두 episode라 도로 균등과 episode 균등 전체 집계가 같다. 각 episode 내 frame 평균 MSE를 먼저 계산하고 episode 평균의 제곱근을 RMSE로 사용했다.

| 집계 | 28 MSE / RMSE | pixel+28 MSE / RMSE | 원래 부호 정확도(28→pixel) |
|---|---:|---:|---:|
| 전체 12 episode | 0.868606 / 0.931990 | 0.878583 / 0.937328 | 70.84% → 69.78% |
| 완주 6 episode | 0.652288 / 0.807643 | 0.634218 / 0.796378 | 99.30% → 99.63% |
| DNF 6 episode | 1.084924 / 1.041597 | 1.122948 / 1.059693 | 42.38% → 39.92% |

전체 RMSE는 0.573% 악화했다. 도로 3/6, episode 4/12에서 MSE가 감소했다. 양의 도로별 MSE 감소량 중 N2 68.80%, N1 25.51%, N3 5.69%로 N2에 집중됐다. 완주 평균 오차의 개선은 N0/N1에 있고, DNF 평균 오차는 악화했다. 특히 N0 DNF의 MSE 증가는 +0.362033으로 전체 악화에 크게 기여했다. 전체 MAE는 0.810557→0.804823으로 소폭 감소했으나 이것만으로 RMSE·부호 정확도 악화를 상쇄해 승격하지 않는다.

독립 episode는 12개뿐이다. 1,145 frame을 독립 표본으로 취급하거나 서로 겹치는 여섯 학습 fold로 표본 수를 늘리지 않았다. 대상은 숨은 미래 macro/RNG commitment를 포함한 실제 sampled return이며 noise-free expected value가 아니다. 두 모델의 구조 차이와 이미 여섯 TRAIN 도로를 사용한 behavior 정책 때문에 순수 영상 인과효과나 새 경쟁 도로 일반화를 확정할 수 없다.

새 데이터·정책·grid·시뮬레이터 실행 없이 종료했다. 새 native action 0, source physics 0, render/actor 호출 0. 다섯 fold 실행 CPU 합계 31.684초, 가장 긴 개별 fold wall 8.225초(동시 실행 wall 합계는 전체 경과시간이 아님); 집계 CPU 0.010초. N2 추가 학습 비용은 0이다.

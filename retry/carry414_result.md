# 414: 한 번의 국소 가속 이득은 전체 주행에 유지되지 않았다

고정 시점 GT 진단을 한 번 실행했다. **공식 완주 없이 196번째 행동의 진행 deadline에서 검열 중단됐으므로 승격하지 않는다.** 사고·손상·도로 이탈 위반은 없었지만, 진행 조건은 실패했다. 관측 경과 15.68초는 랩타임이 아니며, 미관측 남은 주행이나 완주 시간은 추정하지 않았다. 비교 기준 O의 과거 공식 완주는 14.78초다.

413과 같은 초기 상태 및 116행동 prefix, 117번째 행동의 첫 gas=1/brake=0, 이후 원래 O268 자체 관측 피드백을 사용했다. 추가 pulse·시점·gain·horizon 탐색과 재시도는 없었다. 실행 전 actual 310행동/reset 1/CPU 60초/wall 120초, 최대 병렬 1, 모델·학습·SEALED·예비비 사용 0을 동결했다. 물리 안전·재현·진행 조건의 첫 실패에서 중단하고, 공식 완주와 조건 통과가 없는 후보는 승격하지 않는 계약이었다.

초기 full state와 fork가 413 B와 정확히 같았다. prefix 116행동과 suffix 13행동은 명령·상태·controller memory·raw hull·tire를 포함한 공유 기록이 정확히 재현됐다. 기존 413 B1의 body/wheel/raw hull 13행동 fidelity도 통과했다. 새 모델 예측은 하지 않았으며, 129행동 이후의 모델 fidelity를 주장하지 않는다. 고정 시점 GT 진단이므로 배포 가능한 상태 기반 정책의 증거도 아니다.

같은 원래 reference arc를 통과하는 시간 bracket을 비교했다. 새 주행은 raw 20ms, 기준은 129행동까지 저장된 413 A raw 20ms, 이후 저장된 404 O 행동 경계 80ms다. 413 A와 기준 O의 공유 prefix 일치를 확인했다. 보간한 도착 시간은 사용하지 않았다. 같은 진행 위치라도 pose·속도·yaw는 다르다. 아래 이득은 기준 시간−새 시간으로 양수가 빠름을 뜻한다.

첫 손실 marker는 사전 지정한 기준 post-arc 격자 중 첫 확실한 음수다. 정확한 손익 전환점이라는 뜻은 아니다. 70–80% 구간에서 기준/새 주행의 행동 전 arc에 귀속한 시간은 1.36/2.24초, 제동 시간은 0.32/0.72초, 평균 행동 전 속도는 61.34/38.25m/s였다. 이 구간 새 주행의 앞/뒤 q 최대는 0.910/0.823, 마찰 clip 시간은 모두 0이었다. 따라서 이 구간 손실을 새 마찰 포화만으로 설명할 근거는 없다. 구간 시간은 행동 전체의 pre-arc 귀속이며 정확한 경계 분할 시간이 아니다. 정지한 시간도 버리지 않았다. 전체 구간 집계는 [기계 판독 결과](carry414_result.json)에 있다.

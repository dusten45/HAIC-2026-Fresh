새 적분 없이 453의 +270m 이후 손실을 같은 공간 경계로 분해했다. 가장 큰 단일 구간은 pre23 root+450–510m이며 후보가 기준보다 **0.14–0.22초 더 걸렸다**. +450–570m 전체의 직접 crossing 차이는 **0.20–0.28초**다. +270m 이후 총 손실0.30–0.34초의 주된 위치를 찾았으며 제동·조향·상태의 인과 기여는 아직 분리하지 않았다.

+450m crossing 양옆 저장 속도는 기준73.80–74.09m/s, 후보63.57–64.80m/s다. 양옆 표본 범위이며 미관측 연속 시간 속도의 보장 구간은 아니다. 속도 차이는450m 이전부터 발생했다. 위 명령 통계는 제동력의 독립 측정이나 인과 효과가 아니다.

guardian neutral은 양쪽 각1행동/0.08초였다. root 기준 기준326.90–331.62m, 후보327.37–332.01m에서 nominal shadow의 `path_error_over3m` 거절 뒤 선택했다. 450–570m에는 추가 neutral 개입이 없다. late FINISHED certificate는 양쪽13회이며 선택은 nominal이었다. 이는 실제 DONE를 부여하지 않는다. live pending query는 양쪽0회다.

## 442와의 비교 범위

453 기준 전체189개 native rows는442 C0와 정확히 같다. 그러나442의13.760초 후보 P는118행동 prefix 뒤 기존419 시간 순위 planner를54회 사용했고 native119·121·129·132행동에서 fullgas를 선택했다. 공통 pre23 root 기준 약+460.796·470.837·517.876·539.132m다. 453 후보는22행동 prefix 뒤 pre23 pulse 한 번, +270m까지 nominal, 이후 조건부 B였다. **13.760초와14.980초는 같은 정책의 전후 비교가 아니다.** 네 위치와 이번 손실 구간의 겹침은 새 planner 대비를 선택할 근거이며 네 pulse를 복사하면 같은 정책이 된다는 증거는 아니다.

## 저장 자료만 사용하는 재현 방법

1. 비공개453 native trace·각 행동의 after-native post receipt·query records·동결 geometry와442 C0/P 기록을 읽고 입력 SHA256을 고정한다. 원본 state/seed/명령/RNG·개인 문서는 공개하지 않는다.
2. 기존 순수 함수 `executor397.canonical_projection`으로 각 native raw post를 같은 line에 투영한다. 모델·환경 constructor, reset, step을 호출하지 않는다. 각 행동의 시작 progress에서 모듈러 arc 차이를 누적하며 끝 progress가 저장 trace와1e-7m 안에서 같은지 확인한다. posts 수와 raw_ticks, 시간 간격20ms도 대조한다.
3. 원래 pre23 progress를 공통 원점으로270,330,…,750m의 첫 crossing을 찾는다. 직전/직후 native 관측 시각을 bracket으로 남기고 보간하지 않는다. finish는 자기 native 공식 event lap 시각이다. 구간 `[a,b]` 시간은 `[b.lo-a.hi,b.hi-a.lo]`, 후보 추가시간은 `[P.lo-C0.hi,P.hi-C0.lo]`다.
4. 제어 통계는 raw interval progress 중점으로 구간에 배정한다. 속도는 양 끝 속도의 평균에 dt를 곱하고 가스·제동·절대 조향은 해당 interval 명령을 시간 가중한다. 자기 공식 finish 이후 확인 tick은 통계에서 제외한다. 경계에 걸친 제어 bin은20ms 관측 해상도의 기술적 요약이며 crossing 시간과 동일한 적분 정의가 아니다.
5. guardian 선택과 nominal 거절 이유는 저장 query/child receipt에서 집계한다. 각 arm의 중립 제동 총시간, finish certificate와 pending 경로 수를 별도로 남긴다. 이후 새 적분 없이442 prefix·planner 사용·fullgas 선택 횟수를 비교한다.

비공개 재현 스크립트·389개 입력 hash·첫 pass와 finish 확인 tick 제외 정정 pass를 모두 보존했다. 분석 두 pass 합계 CPU6.941초/wall7.394초다. **새 실제 행동/reset/model ticks/worlds/seed/학습은 모두0**이다. 집계는 [JSON](saved454_result.json)에 있다. 이는 기존 모델 적합성 감사나 과거453 비용을 다시 청구하는 작업이 아니다.

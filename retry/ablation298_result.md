# 298 — 여섯 계수의 단일 원복 ablation

**진단에서 선택한 steering gain 원복은 전체 TRAIN에서 16/18 완주로, 296의 17/18보다 낮아 탈락했다.** 공통 15도로에서는 평균 0.492초 빨랐지만 완주 수를 우선하는 사전 조건을 통과하지 못했다. 다른 ablation으로 교체하지 않았고, 297에서 넘겨받은 봉인 DEV 12개는 열지 않았다.

정확한 296에서 gas scale·brake scale·steering curvature gain·lookahead scale·lateral acceleration 공통 배수·speed cap 중 하나씩만 240의 원래 값으로 되돌린 여섯 정책을 고정했다. 나머지 다섯 계수와 perception·tracker·head·memory 구현은 그대로다. 각 ZIP에서 변경된 계수 하나와 다른 다섯 실제 값의 일치, 변경된 모듈만의 차이를 확인했다. 새로운 중간값·조합·계수 탐색·재튜닝은 없다.

진단 TRAIN은 새 정책 결과를 보기 전에 **T2950·T2951·T2953**으로 등록했다. T2950은 296의 기존 실패 도로이며, T2951/T2953은 295에서 296이 추가 완주한 다섯 도로 중 원래 identity 등록 순서의 앞선 두 개다. 296의 기존 결과는 재사용하고 여섯 정책×세 도로의 18개 공식 주행을 모두 완료했다. DEV 12개의 이전 봉인과 identity를 이번 단계로 넘긴 기록도 새 결과 전에 고정했다.

순위는 완주 수 우선, 동률이면 각자의 완주 도로 평균 공식 시간, 다시 동률이면 296 유지와 등록 순서다. gas와 steering 원복은 모두 세 도로를 완주했고, steering 원복의 23.540초가 gas 원복의 24.260초보다 빨라 steering 원복 하나를 동결했다. 296의 두 완주 도로와 비교하면 steering 원복은 평균 0.530초 빨랐다. 서로 다른 완주 집합의 자체 평균은 조건부 값이며, 세 도로 진단만으로 일반적인 속도나 완주 개선을 확정하지 않았다.

선택한 정책은 steering gain만 원래 240의 값으로 되돌린다. 계수와 head 구현은 고정되어도 조향·nominal/head feature와 후속 관측이 바뀌므로 세 행동 채널의 전체 closed-loop stream이 모두 같다는 주장은 아니다.

동결한 steering 원복의 진단 세 결과를 그대로 재사용하고 나머지 15 TRAIN을 한 번씩 평가했다. 전체 18도로에서는 **16/18 대 296의 17/18 완주**였다. T2950을 추가 완주했지만 T2954/T2955의 기존 완주를 잃었다. 공통 완주 15도로의 평균은 0.492초 빨랐고, 자체 16완주 평균은 22.335초였다. 추가 1·손실 2로 전체 완주 수가 한 개 적어 다음 평가에 부적격이다. 특정 도로 손실이나 damage 자체를 별도 veto로 적용하지 않았다.

실패한 winner 대신 gas나 다른 원복 후보를 뒤늦게 선택하지 않았다. 다른 후보의 나머지 15도로 성능은 이번 단계에서 미평가다. DEV는 열지 않고 champion296과 240 rollback을 유지했다. 이 고정 후보 선택과 단일 원복의 결과이며, 원복 ablation 방법군이나 전체 목표의 불가능성을 주장하지 않는다.

실제 비용은 **8,562 native = 진단 4,738/6,000 + 추가 TRAIN 3,824/6,000 + DEV 0/10,000**이다. 33개 새 주행을 모두 공식 종료까지 완료했으며 기술 오류·검열·미실행·중복 실행은 0이다. 전체 실제 wall 354.552초, episode runner CPU 합계 349.811초, 별도 actor CPU 79.165초다. 병렬 episode wall 합계 441.459초는 전체 경과시간과 다르다. raw step 34,212/reset 1,683 tick, source model physics·유료 자원은 0이다.

검증은 단일 계수 원복과 다른 다섯 값 및 코드 보존, 도로 등록 순서, 18개 진단과 15개 추가 공식 결과, 세 결과의 정확한 재사용, 사전 순위·전체 TRAIN gate 재계산, trace와 비용 일치 및 프로세스 회수를 확인했다. 계수·순위·조건을 결과에 맞춰 바꾸지 않았다.

종료 누적 **1,130,598 + 연구 잔여 15,402 + 최종 예비 84,000 = B 1,230,000**이다. 추가 예산 요청 없이 고정 범위를 마쳤다. 예비·HOLDOUT·SEALED·다른 환경은 사용하지 않았고 main·Participants·사용자 변경·기존 백업과 294~297 원결과를 보존했다. 공개는 일반 코드와 집계만 포함하며 개인 원문·raw trace·도로 identity·모델 parameter·ZIP은 비공개로 보관한다.

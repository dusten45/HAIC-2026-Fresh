고정 모델의 소스·정규화·계수 부호를 대수적으로 확인했으며 모델 forward는 호출하지 않았다. 다른15특징과 nominal이 같을 때 count 증가 방향은 raw gas residual 양의 방향·brake residual 음의 방향이다. clip과 양의 final scale 뒤 효과는 줄거나0일 수 있다. “장애물 많음→물리적으로 더 위험함→항상 더 제동”인 단조 위험 법칙이 아니다. 이 조건부 방향만으로 학습 특징이 항상 해롭거나 쓸모없다고 결론 내리지 않는다. 정확한 모델 값은 공개하지 않는다.

**결론은 근거 부족이다.** GT 고유 ID 개수를 runtime 입력으로 쓰는 것은 합법 정보 경계를 넘고, binary 존재는 복수 위험을 지우며, direct-only는 retained 신호를 잃는다. 원래 tracker는 새 직접 검출의2m 안에 있는 이전 예측점을 제거하지만, 실제 관측된 중복은 여러m 드리프트할 수 있다. 거리 cluster·support/age 가중 count는 별개 물체·불확정 birth를 안전하게 보존한다는 근거가 부족하다. frozen head에 count 의미만 바꾸어 넣는 경우에도 원래 학습 분포와의 차이·페달 변화 위험이 남는다.

따라서 지금은 단일 변경 후보나 캐시 반증 계약을 등록하지 않는다. count-only 전체 ablation의 빈칸과 count 의존성 문제는 기록하되, 이를0/1·평균 대입·계수 제거·GT 선택 count의 실행 허가로 해석하지 않는다. 향후 구체적인 합법 대응 근거가 생겨도 full tracker·직접/retained routing·near·최소거리·회피 경로·정상 기억을 먼저 보존하고, 같은 입력에서 count 한 좌표만 바뀌는지와 별개 실제 위험 보존을 사전에 검증해야 한다. 이번에는 그 선행 근거가 확보됐다고 주장하지 않는다.

185 — 접촉 직전 경로·차체 기하와 고정 조향 대조

**작은 우측 조향 대조로 해당 접촉을 피할 수 있었다. 전체 랩 개선은 아직 검증하지 않았다.** 184 중심+ego oracle을 고정하고 남은 DEV 도로의 짧은 구간만 실행했다. 현재 normal24 챔피언을 유지한다.

184의 접촉 전 입력 42~61만 같은 좌표계로 정렬했다. 원점은 공식 `car.hull.position`, 축은 우측 x·전방 y다. 공식 hull 4개와 wheel 4개, 바퀴 연결점과 polygon skin을 확인했다. 바퀴의 모든 조향 방향까지 포함하는 전체 차체 반경은 skin 포함 **2.873564m**다. 각 선분 전체와 시작 연결 선분을 검사한 결과, 52번의 명령 경로에는 모든 장애물·차체 방향에 대해 **최소 +0.029970m**의 보수적 여유가 있었다. 점 차량이나 최근접 waypoint 하나로 안전을 판단하지 않았다. 이는 장애물에 대한 기하학적 여유이며 도로 안쪽 여부·동역학적 추종 가능성의 보증은 아니다.

실제 차량은 61번 입력에서 고정한 52번 경로와 중심 기준 **1.6275m** 떨어졌고, 61번 행동 뒤 실제 8개 fixture의 장애물 간격은 **0.017635m**였다. 저장된 차량 SE2로 정렬한 장애물 좌표 잔차는 1e−9m 미만이었다. 따라서 계획 경로 자체의 필연적 충돌을 확인한 것으로 보지 않고 조향 대조 분기를 선택했다. 후속 실제 재현에서 8개 fixture 형상도 공식 소스와 일치했다.

경로가 소비하는 명목 픽셀 원점 `(42,63)`과 물리 픽셀 중심 `(41.542,62.4475)`은 구분했다. 위 양의 여유는 제어기가 실제 소비한 차체 좌표 경로에 대한 값이다. 픽셀 위치를 다시 해석한 경로의 보수적 경계는 −0.29484m로 판정 불가이며 이를 충돌 증명으로 쓰지 않았다. 좌표를 몰래 이동시키거나 179 기준점 수정·반경 계수 탐색을 추가하지 않았다.

사전에 3개 arm, 시작 52번, 조향 출력 변화량 **0 / −0.08 / +0.08**, 적용 4회(52~55), 종료 82번을 고정했다. 각 arm은 동일한 51회 접두부를 실제로 다시 주행했으며 상태 복제는 없다. 원래 정책은 이후 각 궤적에서 계속 실행된다. 페달·이전 조향 내부 상태를 직접 수정하지 않았지만, 달라진 관측 때문에 후속 경로·페달은 달라질 수 있다. 시작 시점이나 변화량의 추가 탐색은 하지 않았다.

82번은 동일한 native 경과 **6.56초**다. 세 실행 모두 행정적으로 끝낸 짧은 구간이며 공식 DNF가 아니다. 우측은 접촉을 피했으나 진행량이 2 tiles 적었다. 공통 완주 lap 차이·합계·평균·중앙값은 모두 측정하지 않았으며 damage는 독립 진단으로 남겼다. 경로 추종·재계획이 이 접촉에 영향을 준다는 국소 증거는 있으나 유일한 근본 원인이나 일반적인 합법 수정법을 찾은 것은 아니다.

기준 재현은 184의 저장 20행에서 행동·경로·추적·정답 좌표·차체 간격·속도·damage가 정확히 같았고 첫 접촉도 62번의 같은 장애물이었다. 세 arm의 초기 상태, 접두부 관측/행동 hash, 개입 직전 차량 상태·원래 정책 probe가 일치했다. 실제 ego 전파·같은 호출의 대상 목록 보존·목표/P 법칙·스트림 hash·actor 회수 검사를 통과했다. 추가 자격용 정책 호출은 없다.

새 native **246/4,000회**로 종료했다. 실제 접두부 **153회**와 suffix **93회**, raw step **984틱**, reset **153틱**이다. 실행 wall **18.671초**, evaluator CPU **16.548초**, actor CPU **2.785초**이며 저장 산술·준비·게시는 제외했다. **B800,000 = 누적708,199 + 연구7,801 + 예비84,000(사용0)**.

이 단계의 추가 실험은 없다. 향후 별도 범위에서 확인할 대상은 일반적인 경로 추종·재계획 수정의 완주와 공통 lap이며, 합법 ego 추정만 해결하면 된다는 결론은 내리지 않는다. 새 HOLDOUT·SEALED를 닫고 챔피언·main·Participants·기존 백업을 보존했다. 상세 좌표·형상·접두부 hash와 원본 기록은 비공개로 유지했다.

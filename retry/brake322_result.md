# 322: 고정 B brake-only의 전체 TRAIN 검증

321의 B 후보를 수정 없이 유지하고, 진단에 사용했던 세 결과를 재사용한 뒤 나머지 15개 TRAIN을 각각 한 번 평가했다. 전체 완주는 **16/18**, 기준선 296은 **17/18**이다. 사전 완주 수 우선 게이트를 통과하지 못해 이 후보를 기각하고 296을 유지한다. DEV 평가나 승격을 제안하지 않으며 새 실험을 시작하지 않았다.

| 구분 | B 완주 | 296 완주 | 추가 / 손실 | 공통 완주 평균 시간 차이 | 손상 합 B / 296 |
|---|---:|---:|---:|---:|---:|
| 321 진단 세 도로 재사용 | 2/3 | 2/3 | 0 / 0 | −2,680ms (2개) | 0.4 / 0.8 |
| 새 15개 | 14/15 | 15/15 | 0 / 1 | +27.14ms (14개) | 2.4 / 1.4 |
| 전체 TRAIN 18개 | 16/18 | 17/18 | 0 / 1 | −311.25ms (16개) | 2.8 / 2.2 |

시간 차이는 B−296이며 두 정책이 모두 완주한 도로만 포함한다. 전체 시간 개선은 진단 세 도로의 N2 개선에 크게 의존한다. 사후 선택된 진단 세 도로의 성과를 새 15개의 성과나 일반화 증거로 해석하지 않는다. 완주 손실을 조건부 시간 개선으로 상쇄하지 않는다.

새 손실은 T29511이다. 75번째 행동에서 한 번 개입했고, 첫 접촉은 164번째, 공식 crash 종료는 168번째 행동에서 발생했다. 손상은 1.0이다. 조향을 그대로 유지한 brake-only도 이 도로에서는 기준선 완주를 보존하지 못했다. 이것만으로 모든 제동 개입이 해롭다는 결론을 내리지는 않는다.

후보 ZIP·worker·설정은 321 B와 동일하며 319의 기하 모델, 80ms 예측, 표본 수, 트리거, 반사실 조향 개선 게이트, 일회성 latch를 변경하지 않았다. 개입 시 조향은 원래 값, gas는 0, brake는 원래 값과 0.5 중 큰 값이다. 이후 행동과 메모리는 현재 관측을 사용하는 296의 기존 로직을 따른다. 도로별 분기, 새 임계값, 추가 펄스, 학습은 없다. 새 15개에서 10회, 재사용 세 도로에서 3회 개입했다.

4,073개 새 행동의 조향이 원래 조향과 정확히 같은지, 제동 성분과 행동·메모리의 float32 일관성, 원래 메모리 로직과 입력 해시 보존을 검증했다. 모든 15개가 공식 종료까지 관측됐고 기술 오류·검열·미관측은 각각 0이다. 자식 프로세스 회수도 확인했다. 기존 기하 모델의 경고 오차와 표본·동역학 한계는 그대로이며, 이 결과가 충돌 예측의 정확성을 인증하지 않는다.

추가 승인 3,896으로 native 한도 4,468을 등록했고 실제 사용은 **4,073**이었다. 재사용 세 결과는 다시 실행하거나 과금하지 않았다. 실제 step tick은 16,276, reset tick은 765, 평가 벽시계 시간은 286.20초, runner CPU는 209.84초, actor CPU는 70.32초다. 추가 source physics·fit·PPO·유료 자원은 0이다. 누적 native는 1,273,921, 연구 잔여는 **395**, 최종 예비 84,000은 사용하지 않았다. 예산 v331과 비용 원장은 한 번만 닫았다.

현재 champion 296, rollback 240, 기준 main 및 기존 사용자 파일을 보존했다. DEV/HOLDOUT/SEALED는 열지 않았다. 실행용 비공개 ZIP·픽셀·상태·원시 추적·개인 자료는 공개 커밋에 포함하지 않는다. 공개 결과의 도로별 집계는 `brake322_result.json`에 있다. 다음 단계는 이 고정 후보의 확장이 아니라 실패 증거를 반영한 별도 가설 검토이며, 여기서는 실행하지 않는다.

**사전 선택한 중립 조향·제동 pulse 한 번은 같은 C 실패 접근에서 안전한 공통 arc 통과를 보였다.** 원래 C는 103번째 행동에 경로 오차 4.760m로 중단됐고, pulse는 107번째 행동에서 그 arc를 안전하게 넘었다. 그러나 더 늦게 도달했고 전체 랩은 실행하지 않았다. 이 결과는 알려진 DEV 상태 하나의 국소 증거이며, 랩·11초 목표·296 개선이나 독립 일반화의 증거는 아니다. ## 실행 전에 고정한 비교

406에서 제안하고 선택한 두 arm만 한 번씩 실행했다. 고정된 C+268, 같은 실제 reset과 90행동 prefix를 사용했다. 기준은 원래 C 그대로, 변경은 91번째 행동 한 번만 `steer=0, gas=0, brake=float32(0.3)`이었다. 기준의 해당 명령은 `[0.0023847024, 0.8516305089, 0]`이다. 조향·구동 제거·제동이 함께 바뀌므로 제동 단독 인과 효과를 분리하지 않는다.

92번째부터 원래 C가 자기 실제 상태로 명령을 계산했다. nominal 계산과 controller memory 갱신은 원래대로이며 pulse 조향을 nominal laststeer에 주입하지 않았다. 사전에 동결한 것은 이 실행 규칙과 한 pulse다. 저장된 모델 미래 명령열을 실제로 강제하지 않았다. 미래 실제 상태는 제어 입력으로 사용하지 않았다.

최대 228 wrapper, reset 2회, arm당 90+24행동, CPU 60초·wall 120초·동시 1개를 등록했다. 최근404 C의 103행동 CPU 9.475초를 228회로 환산한 약21초에 reset·full capture·대조 여유를 더했다. 새 후보·gain·horizon·재시도·source 모델 적분·actor·학습·SEALED·유료 자원·예비 사용은 0이다. 계획 SHA256은 `3549d00e29835fa44299754d057548626a4481b6c59c9c43f570ec37b241f5c2`다.

자격·source·prefix·모델 fidelity·기술·자원·기한 실패는 나머지 실행도 중단하도록 고정했다. 예상된 기준 C의 103행동 경로 오차 중단은 그 arm만 끝내며, 다른 prefix 또는 기준 재현 실패는 전체 중단이다. 기존 3m·충돌/새 장애물 접촉·손상 증가·도로 접촉 상실/raw grass·의미 있는 후진·domain 중단 기준을 유지했다. 최초 안전 위반은 실제 DNF와 구분해 검열로 기록했다.

## 자격과 모델의 실제 대조

두 초기 full 이용 가능 상태·RNG·픽셀은402와 같았다. 두 arm의 prefix90 센서·명령·nominal memory·reference·결과는404와 정확히 일치했다. pre91에서 두 새 arm의 full 이용 가능 물리 상태·접촉·RNG·픽셀·C/nominal 계산 전후 memory도 같았다.404에는 그 mid-fork full snapshot이 없으므로 전체 물리 상태가 과거와 비트 일치한다고 주장하지 않는다. 기준 C는 전체103행동의 저장 센서·명령·결과를404와 재현했다.

## 13행동 안전과 공통 arc 도달을 분리

pulse의 103번째 행동은 원래 실패 arc보다 여전히 **15.110m 앞**이었다. 여기까지의 안전만으로 회복 성공을 세지 않았다. 같은 episode에서 원래 C를 계속 실행해 106번째에는 목표보다0.356m 앞, 107번째에는4.978m 지난 지점이 관측됐다. 107번째의 경로 오차는0.190m였고, pulse 이후17행동 전체의 최대 경로 오차는0.573m였다. 충돌·손상 증가·도로 상실·후진 중단은 없었다.

따라서 이번에는 406의 '위험 위치에 아직 도착하지 않음' 제한을 넘어 **같은 실패 arc의 안전한 관측 통과**를 얻었다. 다만 정확히 같은 arc의 상태를 보간해 비교한 것은 아니다. 최초 관측 통과는 원래 C의103번째보다4행동·0.32초 늦었다. 실제 목표 통과는106–107 사이이므로 관측 간격 기준 지연 범위는 약0.24–0.32초이며,0.32초는 최초 관측 지연이다. 지연과4.978m overshoot를 시간 개선으로 해석하지 않는다. 공통 arc를 넘자 종료했으며, 남은7행동을 더 쓰지 않았다.

기준 C는 손상0이지만 경로 오차 안전 중단이었으며 환경 DNF가 아니다. pulse도 전체 랩을 완료한 결과가 아니다. 전체 episode 최대 경로 오차1.379m는 공통 prefix의28번째에서 발생했다.

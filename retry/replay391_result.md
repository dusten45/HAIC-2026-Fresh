# 391 — 두 저장 상태의 12행동 전이 재현

390에서 제안한 게이트를 실행했고 **두 상태 모두 12행동을 통과**했다. 신규 wrapper·actor·환경 reset·학습은 **0회**, source 모델 양의 시간 **96tick**, 실행 CPU **0.083초**였다. 연구 잔여 **34,139회**, 최종 예비 **84,000회 미사용**, 296 유지와 SEALED16 미개봉 상태는 그대로다. [집계·행별 오차](replay391_result.json), [실행 코드](replay391_run.py), [앞선 측정](probe390_result.md)

실행 전에 소스·저장 자료 hash, 상태 순서, 행동 범위, 오차 기준·중단 기준과 비용 상한을 동결했다. 390의 N1 pre64 직선 capture에서 **64–75번 행동**, pre94 코너 capture에서 **94–105번 행동**을 재생했다. 각각 첫 행동은 390에서 검증했던 행동이고 뒤의 11행동을 더 확인한 것이다. 사용한 명령은 389에 저장된 실제 296 행동이며 새 actor 추론이나 teacher 미래 명령이 아니다. 각 복원 world에서 중간 상태 보정 없이 연속 0.96초를 전진시켰다.

390과 같은 기준을 매행 적용했다: 속도 절대 오차≤0.5m/s, yaw rate 절대 오차≤0.05rad/s, 위치 L2 오차≤0.10m. 초기 body/tiles/progress 일치와 충돌·손상·바퀴 도로 접촉 개수의 일치도 요구했다. 최초 초과 시 해당 상태를 중단하고 다른 고정 상태는 독립적으로 확인하도록 등록했다. 기술 오류·CPU60초·모델96tick·승인 종료 시에는 전체를 중단하며 재시도·상태 대체·기준 조정은 허용하지 않았다.

24행 모두 충돌·손상·바퀴 도로 접촉 개수가 일치했다. 추가 진단인 방문 타일 수와 off_track counter도 모두 일치했다. **기준을 넘은 최초 불일치는 없지만 비트 단위 완전 일치는 아니다.** 직선64의 첫 행동부터 속도 약7.95e−7m/s, yaw rate 약3.36e−7rad/s 차이는 있었다. 이를 실패로 바꾸거나 오차가 0이었다고 보고하지 않았다.

이 결과로 배제한 것은 **이 두 저장 상태와 실제 명령열에서 12행동 이내에 등록 기준을 넘는 복원 오차가 생겼다**는 설명이다. solver warm-start·manifold·island 순서가 완전히 복원됐다는 증거는 아니다. 바꾼 명령열의 12행동 후보 순위, 새로운 상태·접촉 상황, 전체 lap의 최적성·일반화·공식 시간 적합성은 미검증이다. 390의 한 행동 순위 확인과 이번 실제 명령열 재현을 합쳐도 전체 MPC 자격으로 확대하지 않는다.

다음은 사용자 지시에 근거한 순서이며 원문 적용 계획을 대신하지 않는다.

1. 이 환경에서 Library `prepare_materialize` 기능이 제공되면, 비공개 체크포인트의
   정확한 두 Library ID와 파일명을 사용하고 목적지를 이 프로젝트 루트로 지정한다.
   반환 transfer와 현재 공식 helper 지침을 따른다. 반환 경로가 이 실행기에
   없으면 로컬 목적지를 명시한 지원 재시도를 한 번만 한다.
   Sediment 다운로드가 실제 제공되면 사용자 지정 file ID도 지원 경로로 확인한다.
2. 실제 로컬 파일의 존재·읽기 가능·파일 크기·SHA-256을 확인한다. 전체 본문,
   표 및 필요한 그림을 읽고 누락 여부를 확인한다. 추출본과 읽기 기록은 비공개로 둔다.

4. 공식 코드의 문제 계약, 관측 전용 정책/특권 진단/oracle 경계, 현재 자원과
   시뮬레이션 비용을 확인한다. DEV/HOLDOUT/SEALED를 누출 없이 분리하고 동결한다.
5. 모든 방법군의 비교·작은 반증 실험·중단/승격 기준을 사전에 정한 뒤 실험한다.

# 2026-10-07 초기 진단 결과

재도전의 환경 진단을 시작했다. **필수 원문 전체 접근 게이트가 막혀 있어 방법론
적용, 방법군 선택, 후보 승격 및 학습은 시작하지 않았다.** 아래 실측은 원문을
대체하지 않는다. 사용자 지정 7일 실제 실행을 완료했거나 장기 작업이 계속
실행 중이라는 의미도 아니다.

## 실제 확인

- 작업 시작 시 tracked/untracked 작업 변경은 없었으며 `work` 브랜치였다.
- HEAD, 로컬 main, origin/main, 원격 main은 모두
  `dfb7a2de2178825ca5c5ce20bab01ba67052ba31`이고 main은 18개 커밋이다.
- 원격 `backup/main-before-participants-restore-20261007T113855Z`는
  `62447fcc67518697bf83c2f5286015cb9dd387c5`다.
- `/AGENTS.md`, `/workspace/AGENTS.md`, 저장소 내 `AGENTS.md`는 없었다.
  workspace `.agents`는 비어 있고 저장소에는 `.agents/skills`가 없었다.
- 기존 가상환경과 ignored 디렉터리를 보존했다. 저장소 초기화, 이력 복구,
  force push, 공식 Participants 저장소 변경은 수행하지 않았다.
- 기존 테스트는 16개 중 **15개 통과, 1개 skip**이다. skip은 비교 대상 서버
  저장소 부재이며 서버 코드와의 동일성 증명이 아니다.

픽셀 렌더링, 전처리, 공식 frame skip을 모두 유지했다. `render_mode=None`은

모으면 약 34.13 행동/초였고, reset은 0.388~0.466초였다. 기본 예제의
`safe_act` p95는 에피소드별 0.82~2.07 ms였다. 후보 신경망의 비용을 뜻하지 않는다.

같은 4 에피소드(332 행동, 1,324 raw action tick)를 각 병렬도로 1회 측정했다.
아래 벽시계는 새 프로세스 시작·종료와 reset을 포함한다.

각 조건 1회이고 기본 예제는 일찍 종료하므로 이 결과로 최적 병렬도나 7일
학습량을 확정하지 않는다. 학습·모델 추론·체크포인트 저장 비용과 장시간
경쟁 자원 상황은 미측정이다. 금전 비용 정보도 제공되지 않았다.

## 반증 결과와 실패로 배운 점

1. 같은 `(track_id=1, seed=42)`를 재실행한 픽셀·행동·보상·종료 해시는 같았다.
   1/2/4 workers의 대응 에피소드에서도 해시가 같았다. 이는 이 설치와 이
   짧은 입력들의 재현성 근거이며 다른 설치 전체의 결정성 보장은 아니다.
2. seed 42에서 track_id 1과 2의 도로 기하 해시는 같고 장애물 해시는 달랐다.
   **(track_id, seed) 쌍만 분리하면 같은 도로가 DEV와 평가 집합에 섞일 수 있다.**
   이번에 노출한 seeds 42·43·44는 모든 track_id에 대해 DEV로 고정 취급한다.
3. 무동작 진단은 음수 보상 누적 조건에 따라 101 행동에서 종료됐다.
4. 기본 가속 예제는 seed 42에서 43 행동/170 raw tick 후 플레이 영역 이탈,
   seeds 43·44에서는 123 행동 후 off_track이었다. 진단에서 완주는 없었다.
   이 결과는 기본 예제의 환경 점검 결과이며 학습 가능성이나 특정 방법군
   우열을 보여주지 않는다.
5. 첫 결과 분석에서 `raw_ticks == 4 * actions`라는 검증식을 사용해
   **AssertionError**가 발생했다. 공식 wrapper는 종료가 발생하면 frame skip
   중간에 멈춘다. 43번째 행동에서 2 tick만 실행된 170 tick이 올바른 값이다.
   검증을 `4*(actions-1) < raw_ticks <= 4*actions`로 수정했고 전체 결과가
   통과했다. 시뮬레이터나 측정 원자료는 수정하지 않았다.

## 코드에서 확인한 문제 계약

근거는 현재 커밋의 `README.md`, `agent.py`, `local_runner.py`,
`env_wrapper.py`, `core/finish_line.py`, `core/vendor/car_racing.py`다.
원문 방법론 적용을 완료한 최종 계약은 아니다.

| 항목 | 확인한 계약·검증 범위 |
|---|---|
| 합법적 정책 입력 | float32 `(4,84,84)`, 범위 [0,1], 최근 흑백 프레임 4개. reset/act에는 이 배열만 전달 |
| 정책 출력 | steer [-1,1], gas/brake [0,1], 유한한 값 3개; local_runner의 safe_act 검증 사용 |
| privileged 진단 | 도로·장애물 해시, 환경 내부 시간/진행률/손상은 진단 결과에만 기록; 정책 입력·선택에 전달하지 않음 |
| 학습 보상 | 새 타일 +1000/N, raw frame -0.1 및 영역 이탈 처리. 진단용 reward 열은 순위 점수가 아님 |
| 실제 순위 | 완주가 미완주보다 우선. 완주는 시뮬레이션 lap time이 짧을수록, 미완주는 진행률이 높을수록 우선. 실행 실패 제외 |
| 완주 | 타일 95%는 자격 조건; 출발영역 이탈 후 정상 방향 결승 재통과·앞 영역 이탈 필요 |
| 공식 시간 | reset 준비 후부터 결승 중심을 통과한 50 FPS tick까지. 측정 wall time과 구분 |
| 행동 간격 | 기본 4 raw frames, 중간 종료 시 실제 수가 줄어듦 |
| 실행 한도 | README: import+생성 10초 / reset 5초 / act 5초 / 참가자 메모리 1,024 MB / invalid 10회 연속 리타이어 |
| 로컬 차이 | safe_act는 thread 기반. 로컬 runner가 서버의 프로세스 격리·메모리·import 시간 제한을 재현한다고 증명하지 않음 |
| 평가 범위 공백 | 서버 공통 파일 대조 skip. 실제 다중 트랙의 집계 규칙·공식 action budget은 이 진단에서 별도 확정하지 않음 |

향후 privileged teacher·학습 레이블을 사용하려면 먼저 원문과 대회 계약을
확인해야 한다. 진단 접근 허용을 제출 정책의 privileged 입력 허용으로
해석하지 않는다. 성능을 낸 적 없는 예제의 낮은 메모리 사용을 향후 모델의
1,024 MB 제한 통과 증거로 사용하지 않는다.

## 환경 차단

지정된 방법론 문서(68쪽·24장)와 적용 계획(27쪽)의 전체 원문은 아직 읽지
못했다. 페이지 수는 사용자 제공 정보이며 파일에서 검증한 값이 아니다.
현재 Library 기능 목록에는 create/replace 및 upload 준비·완료만 있고,
`list`, `search`, `read`, `find`, `prepare_materialize`가 없다. 따라서
지원되는 원문 조회·물질화 호출 자체를 시작할 수 없었다.

이는 파일이 없다는 판정이나 권한 거부 응답이 아니다. 다른 executor의 경로,
추측한 다운로드 URL, 저장소 사본으로 우회하지 않았다. 로컬 경로가 반환된
호출도 없으므로 소비자 목적지를 명시한 재시도 조건은 아직 발생하지 않았다.
원문과 개인 회고의 공개 저장소 게시도 없었다.

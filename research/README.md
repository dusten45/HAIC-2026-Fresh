# 개인 재도전: 초기 환경 진단

이 디렉터리는 제출 코드가 아닌 로컬 실험 운영 도구와 공개 가능한 기록이다.
`agent.py`, 공식 물리·전처리 코드는 변경하지 않는다. 원문 문서와 개인 회고는
여기에 저장하지 않는다. 계산은 현재 Codex 클라우드 환경에서만 한다.

## 선행 게이트와 현재 범위

필수 방법론 원문 24장 및 구체적 적용 계획 전체의 소비 환경 접근·완독은
아직 **차단** 상태다. 현재 제공된 Library 도구에는 조회, 읽기,
`prepare_materialize`가 없다. 원문을 내려받았거나 읽었다고 주장하지 않는다.
대체 요약, 과거 실험 결과, 이전 알고리즘 선호로 이 게이트를 통과시킬 수 없다.

따라서 지금 허용하는 작업은 저장소 상태 확인, 기존 계약 테스트, 변경 없는
공식 예제의 실행 비용 및 결정성 진단이다. 방법군 선택, 학습, 후보 승격,
HOLDOUT/SEALED 성능 평가는 원문 게이트와 사전 평가 설계 이후에 한다.

## 실행 전 등록한 작은 진단 (2026-10-07)

진단은 성능 경연이 아니며 아래 고정된 예제/입력을 사용한다.

| ID | 반증할 가정 | 절차 | 판정·중단 기준 |
|---|---|---|---|
| P0 | 현재 설치에서 기본 계약을 만족한다 | 기존 `unittest` 전체 | 실패 시 환경 수리 전 후속 실험 중단. 서버 대조 skip은 검증 공백으로 표시 |
| P1 | 동일 seed·track·행동에서 관측과 결과가 재현된다 | `(1,42)` 기본 예제 2회 | 픽셀/행동/보상/종료 해시 불일치 시 평가 설계 중단 |
| P2 | `track_id`만 다르면 독립 도로 표본이다 | `(1,42)`와 `(2,42)`의 도로 기하 해시 비교 | 같으면 seed 단위로 DEV 오염 범위 확대; pair 단위 분할 금지 |
| P3 | 실제 픽셀 관측을 유지한 시뮬레이션 비용을 안다 | 예제 정책, seeds 42·43·44, 최대 256 행동/회 | reset·step·safe_act·벽시계·CPU·RSS 측정. 렌더 제거로 속도 과장 금지 |
| P4 | 4코어 할당에서 프로세스 증가가 선형 이득이다 | 같은 4회 workload를 1/2/4 workers로 각 1회 | 처리량 실측만 기록, 단일 측정으로 최적 병렬도 확정 금지 |
| P5 | 움직임이 없으면 음수 보상 연속 종료를 관찰한다 | `(1,42)`의 무동작 진단 1회 | 101 행동 종료 여부 기록, 대회 주행 전략으로 평가하지 않음 |

각 실행은 외부 `timeout 120s`로 제한한다. 총 계획은 짧은 에피소드 18회 이하,
각 256 행동 이하, 최대 동시 프로세스 4개다. 모든 후보 학습은 0회다.
유효하지 않은 관측·행동 또는 결정성 실패는 후속 평가의 중단 조건이다.
상수 예제의 결과는 미래 모델의 완주율이나 충분한 학습량 추정 근거가 아니다.

실행한 seed 42·43·44는 모든 track_id에 대해 DEV 오염으로 취급한다.
아직 HOLDOUT/SEALED seed를 생성하거나 실행하지 않는다. 향후에는 원문을
반영한 별도 manifests, 중복 기하 검사, 접근·실행 로그, 사전 후보 동결이 필요하다.

## 재현

저장소 루트에서 기존 `.venv`를 사용한다. 설치나 저장소 초기화는 반복하지 않는다.

```bash
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m unittest discover -s tests -v

SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  timeout 120s .venv/bin/python -m research.initial_probe \
  --output research/results/initial_probe.json
```

진단 코드의 환경 내부 접근은 결과 기록 전용이다. `Agent.reset/act`에는
공식 `(4,84,84)` float32 픽셀 배열만 전달한다. 진단 모듈은 제출 ZIP에 넣지 않는다.

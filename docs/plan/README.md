# Plan Index

Read [COMMON.md](COMMON.md) before the plan for your assigned task. The shared
contract and the task-specific plan together define the research contract.
Follow the selected plan's current phase, scope, and gates; this index does not
authorize starting or resuming any task.

## Shared Contract

- [COMMON.md](COMMON.md): shared research contract, original Phase 1-2 gates, exposed oracle evaluation roads, and frozen oracle-v1 checkpoint.

## Task Plans

- [BC.md](BC.md): trajectory collection, learned-policy training, and BC diagnosis; includes Phase 3/4 splits and gates, geometry/observability diagnosis, and BC status. Update for learned-policy work only.
- [ORACLE_V2.md](ORACLE_V2.md): separate high-speed local teacher experiment and v2 checkpoints. Update for oracle-v2 work only.
- [ORACLE_V3.md](ORACLE_V3.md): frozen leaderboard-targeted teacher checkpoint on the three designated exposed roads.
- [ORACLE_V4.md](ORACLE_V4.md): separate coupled-grip planning and feedforward teacher improvement, preserving frozen v3.
- [TEACHER_COMPARISON.md](TEACHER_COMPARISON.md): small teacher generalization gate and matched v1/v2/mixed-data BC pilot.
- [CLEANUP.md](CLEANUP.md): user-authorized research-tool maintenance scope and validation gate; does not resume research experiments.

## Adding Plans

For a new user-authorized independent task, create a separate clearly named plan
in this directory and add its purpose and link to this index. Do not update
`AGENTS.md` merely to register a new plan. Keep task checkpoints in the relevant
plan and coordinate shared-contract changes before editing.
